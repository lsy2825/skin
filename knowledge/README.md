# 시술 지식 베이스 (Treatment Knowledge Base)

앱의 시술 설명(시술 사전, 비교 탭의 설명 카드, 검색의 '종류' 안내, 시술 퀵뷰)은 모두 `knowledge/treatments.json` 한 파일에서 나와요.
가격 데이터와 분리돼 있어서, 의료진이 이 파일만 고쳐도 다음 빌드부터 앱에 반영돼요.

## 원칙
- 초보자가 이해할 수 있는 말로 써요.
- 효과를 약속하거나("좋아져요", "확실히"), 증상에 따라 특정 시술을 권하지 않아요.
- "주로 무엇 때문에 받아요"처럼 일반적인 목적만 적어요.
- 부작용·주의사항은 공개된 근거 자료(공공기관, 학회, 리뷰 논문)와 대조한 것만 출처를 달아요. 대조하지 못한 항목은 `sources`를 비우고 `evidence_note`에 그렇다고 적어요(앱에는 '근거 자료 미정리'로 보여요).
- 새로 쓴 항목은 항상 `draft`(초안·전문가 검수 전)로 시작해요. 앱의 모든 설명 아래에 검수 상태와 "진단·효과 보장 아님, 의료진 상담" 문구가 붙어요.

## 항목 형식
| 필드 | 뜻 |
|---|---|
| `id` | 고유 이름(영문) |
| `title` | 보여줄 이름 |
| `families` | 이 설명을 쓸 비교 제품군 이름(`build2/taxonomy.py`가 만든 이름, 예: `사각턱 보톡스`) |
| `fids` | 제품군 이름 대신 분류표의 기본 제품 id로 연결(예: `hair` → 모든 '… 제모') |
| `base` | 공통 내용을 물려받을 항목 id(예: 부위별 보톡스 → `base-toxin`) |
| `one_liner` | 쉬운 한 줄 설명 |
| `purpose` | 일반적인 시술 목적 |
| `areas` | 사용 부위 |
| `method` | 시술 방식의 기본 차이(비슷한 시술과 무엇이 다른지) |
| `kinds` | 관련 브랜드·종류 |
| `side_effects` / `extra_side_effects` | 주요 부작용(물려받은 목록에 더할 때는 `extra_…`) |
| `cautions` / `extra_cautions` | 주의사항 |
| `sources` | 근거 출처 id 목록(파일 위쪽 `sources`에 제목·기관·URL·확인일·확인 방법) |
| `evidence_note` | 근거를 어떻게 정리했는지, 무엇이 아직 확인 안 됐는지 |
| `review` | `status`(draft / in_review / approved / needs_changes), `reviewer`, `reviewed_at`, `notes` |

## 전문가 검수 방법
1. **의견만 줄 때:** 앱의 설명 아래 "검수 의견 보내기"를 눌러요. 항목 id가 채워진 GitHub 이슈(라벨 `knowledge-review`)가 열려요. 운영자가 반영해요.
2. **직접 고칠 때:** 이 파일을 GitHub에서 편집해 PR을 올려요.
   - 검수를 마친 항목은 `review.status`를 `approved`로 바꿔요.
   - `reviewer`(이름·소속 또는 면허 종류)와 `reviewed_at`(YYYY-MM-DD)을 적어요.
   - 고칠 점이 남았으면 `needs_changes`로 두고 `notes`에 적어요.
3. **자동 검사:** `python build2/knowledge.py`가 배포 전에 아래를 확인해요. 실패하면 배포하지 않아요.
   - 필수 필드, 상태 값, 출처 id가 맞는지
   - `approved` 항목에 검수자·검수일·출처가 있는지
4. **검수 현황 보기:** 앱의 내정보 → 운영 현황 → '시술 설명 검수 현황'에서 볼 수 있어요.

- 항목 49개, 모두 `draft`(전문가 검수 전)예요.
- 출처가 붙은 항목은 36개예요. 공통 항목에서 물려받은 것 포함이에요.
  - 출처 기관: FDA, 미국피부과학회, 식약처, Mayo Clinic, Cleveland Clinic, 리뷰 논문
  - 출처는 검색 결과 요약으로 확인했어요. 본문 전체를 읽지 못한 출처는 `how`에 그렇게 적었어요.
- 출처가 없는 항목은 13개예요. 일반적으로 알려진 내용만 적었고 '근거 자료 미정리'로 보여요.
  - 해당 항목: 지방·윤곽 주사, 실리프팅, 온다, PN 주사, 엑소좀, 혈관 레이저, 프락셔널, 미세바늘 고주파, 아쿠아필, 점 제거, 염증주사, 문신제거, 영양주사
- 설명 항목이 없는 제품군은 `python build2/knowledge.py --families`로 볼 수 있어요. 앱은 이런 제품군에 병원이 상품명에 적은 설명만 보여줘요.

## 3. 개인정보

- 사진 원본은 저장하지 않음(분석 요청에만). 앱 업로드 시 EXIF 제거는 업로드 화면을 만들 때 구현 예정(아직 없음).
- 견적 원문은 그 사람의 보고서에만, 공유 요약에는 넣지 않음(테스트).
- 공유 링크는 무작위 64자, 요약만(사용자 ID·원문 없음), 보고서를 지우면 링크도 무효(api 6).
- 푸시에는 내용이 없음. 로그에는 토큰·카드·사진을 남기지 않음(`worker.mjs` 로그 정책).
- 결제 원문은 마스킹한 필드만 저장(카드 번호는 토스가 이미 가린 값).

## 4. 남은 위험

- 서버가 실제로 배포·침투 시험되지 않았어요. 운영 전 외부 보안 점검 권장.
- 요청 제한이 메모리 기반(워커 인스턴스마다 따로)이라 운영에서는 공유 저장소로 바꿔야 해요.
- Cloudflare Workers에서 node:crypto `X509Certificate` 지원 여부는 확인 전(Apple 검증).

| 질문 | 확인 방법 | 결과 |

| 지점별 비교가 같은 스펙 기준인가 | 시술 12개(수작업 3 + 분류표 9, 용량이 이름에 있는 것)의 비교 목록 644개 가격을 확인. 모두 그 비교 키의 상품이고, 이름의 용량이 키와 같았어요. 장바구니 지점별 견적도 같은 키 상품인지 확인 | 통과 |
| 필터를 바꿔도 장바구니가 유지되나 | 지역(수도권→전국), 브랜드 칩, 가격표 분류, 부가세 표시, 특가 스위치를 바꾸고 새로고침. 수량까지 같았어요 | 통과 |
| 예산 숫자와 슬라이더가 동기화되나 | 숫자 → 슬라이더, 슬라이더(마우스·키보드 →) → 숫자, 빠른 금액 → 둘 다, 잘못된 금액(-5) 안내, '제한 없음' → 둘 다 비움 | 통과 |
| 가격 없는 항목이 0원으로 계산되지 않나 | 2개 중 1개만 파는 지점을 열었어요 | 통과 |
| 지도 마커와 지점 목록이 맞게 연동되나 | 마커 4개 → 목록 강조(이름·가격 일치), 목록 📍 3개 → 같은 지점 팝업, 같은 좌표 지점 2곳 | 통과 (처음 실행 때 실패 → 고침, 아래) |
| 시술 가이드의 가격비교 버튼이 맞는 시술을 고르나 | 시술 사전 302개 중 35개 표본, 제모 부위 버튼 5개, 설명 시트 버튼 4개(사각턱·주름·스킨보톡스, 리쥬란). 비교 화면에서 고른 제품군이 같았어요 | 통과 |
| (추가) 머리말 지점 수 = 지역 메뉴 지점 수 | 수도권·전국·서울 | 통과 |

0원 항목 질문에서 본 화면이에요.
- 지점 줄: "2개 중 1개 가능 · 없음: …"
- 없는 시술: 0원이 아니라 '없음'
- 합계: 확인된 시술만 더한 값(49,500원 = 줄 합)
- 문구: "확인된 시술 합계"와 "합계에 넣지 않았어요(0원 아님)"

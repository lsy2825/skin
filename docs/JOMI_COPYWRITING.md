# 죠미 대사 (Copywriting)

기준일: 2026-10-13. 대사는 `app/jomi.js`의 `JOMI.lines` 한 곳에 있어요. 고칠 때는 그 파일만 바꾸면 돼요.

## 원칙
- **짧은 반말.** 한 번에 1~2문장만 써요.
- **다정하지만 담백하게.** 아기 말투, "~냥", 과한 애교, 느낌표 연발은 쓰지 않아요.
- **결정은 사용자 몫.** 죠미는 권하지 않고 비교하게 도와요.
- **의학 판단 금지:** "진단", "너에게 맞는", "추천 1위", "효과 보장", 용량 숫자를 쓰지 않아요.
  - 의학 설명은 지식 파일 문장을 따로 보여줘요(죠미의 말이 아님).
- **사실만.** 오류는 실제로 실패한 것(가격 파일을 못 읽음)만 말하고, 원인을 지어내지 않아요.
- **성공은 실제 성공 뒤에만.** 알림 토스트는 저장을 확인한 다음에 띄워요.

## 대사 목록
| 키 | 대사 | 쓰는 곳 |
|---|---|---|
| `intro` | "안녕! 난 죠미야!" / "시술 이름도 어렵고 가격도 헷갈리지?" / "내가 다양한 시술 정보를 쉽게 알려주고, 병원별 가격도 비교할 수 있도록 도와줄게." / "궁금한 게 있으면 언제든 찾아와!" | 첫 소개(지시서 문구 그대로) |
| `back` | "또 왔네! 오늘은 어떤 시술이 궁금해?" | 재방문 소개 |
| `homeFirst` | "안녕! 오늘은 어떤 피부 고민이 있어?" | 홈 인사(소개를 보기 전) |
| `homeBack` | "또 왔네! 오늘은 어떤 시술이 궁금해?" | 홈 인사(본 뒤) |
| `does` | "어려운 시술 이름을 쉽게 풀어 줘" / "같은 용량·회차끼리 병원별 가격을 비교해" / "가격이 내려가면 앱을 열 때 알려 줘" | 소개의 '하는 일' |
| `doesNot` | "나는 의료진이 아니라서 진단이나 시술 추천은 하지 않아. 정보만 정리해 줄게." | 소개 |
| `loading` | "오늘의 가격을 살펴보는 중…" | 시작·다시 시도 로딩 |
| `slow` | "평소보다 오래 걸리고 있어. 인터넷 연결을 확인해 줄래?" | 12초 넘게 로딩 |
| `error` | "잠깐 문제가 생겼어. 다시 시도해 볼까?" | 가격 파일을 읽지 못함(아래에 해요체 설명) |
| `concernAsk` | "어떤 점이 고민인지 편하게 적어줘. 관련된 일반 정보와 시술 설명, 확인할 위험과 한계를 찾아볼게." | 고민 가이드 첫 말풍선 |
| `concernFound` | "적어 준 말과 관련된 정보를 찾아봤어. 결정은 꼭 의료진과 상담해서 해 줘." | 고민 결과 위 |
| `guideTip` | "스킨보톡스랑 주름보톡스는 뭐가 다를까? 이름이 비슷한 시술을 쉽게 정리했어." | 시술 사전 |
| `emptySearch` | "아직 찾지 못했어. 검색 조건을 바꿔볼까?" | 검색 결과 없음 |
| `emptyCart` / `emptyCartSub` | "아직 담은 시술이 없네!" / "관심 있는 시술을 담으면 병원별 비용을 비교할 수 있어." | 빈 장바구니 |
| `saved` | "저장했어! 관심 탭에서 다시 볼 수 있어." | 관심 저장 토스트 |
| `added` | "담았어! 장바구니에서 병원별로 비교해 볼 수 있어." | 담기 토스트 |
| `alertSet` | "좋아! 조건이 맞으면 알려줄게." + (저장된 조건 요약) | 알림 저장 토스트 |
| `easter` | "비교는 내가, 결정은 네가!" / "같은 용량끼리만 비교하는 게 내 원칙이야." / "가격표 읽는 게 제일 재밌어." / "체험가는 보통 1인 1회야. 꼭 확인해!" / "간지러워!" | 소개 시트에서 죠미를 누를 때 |

- 지시서 예시 "좋아! 가격이 내려가면 알려줄게."는 "조건이 맞으면"으로 바꿨어요.
  - 알림 종류에는 '파는 지점이 늘면'처럼 가격과 무관한 것도 있어서, 사실과 맞게 고쳤어요.

## 바꾸지 않은 문구 (해요체 유지)
- 가격·조건·출처 설명, 의학 설명(지식 파일), 법적 안내(진단·추천 아님, 저장 안 함)
- 버튼 이름: 담기, 알림, 되돌리기, 다시 시도 …

# 죠미 대사 (Copywriting)

기준일: 2026-10-14. 대사는 세 곳에 있어요.
- `app/data/jomi_lines.json` — 상황 대사 2,011개(레코드 64, 의도 25). 첫 화면 뒤에 따로 읽어요. 대부분의 대사는 여기서 고쳐요.
- `app/domain/jomilines.js` — 선택 규칙과 내장 대사 47개(파일을 못 읽을 때), 고정 안전 문장 3개(`fixed`, 파일로 바꿀 수 없음).
- `app/jomi.js`의 `JOMI.lines` — 소개 시트·장난 문구 등 아래 목록(예전 레지스트리, 그대로 유지).

## 대사 파일 규칙 (`tests/jomilines.test.js`가 검사)
- 60자 이하 반말. 해요체 끝맺음(요·니다·세요)은 실패로 봐요.
- 금액·%·병원(체인) 이름·의학 단어(진단·처방·추천·효과·부작용·보장·용량 권장·최저가)·외모 평가 금지.
- 같은 문장 두 번 금지, 한 레코드 안에서 한두 글자만 다른 문장 금지.
- 앱이 부르는 모든 의도(`jline("…")`)에 대사가 있어야 해요. 고정 안전 문장은 파일을 읽어도 그대로예요.
- 레코드 조건: `visits`(방문 횟수), `hour`(시간대), `dow`(요일), `month`(달, [12, 2]처럼 해를 넘길 수 있음), `offline`. 값이 없으면 조건부 레코드는 빠져요.

## 원칙
- **짧은 반말.** 한 번에 1~2문장만 써요.
- **다정하지만 담백하게.** 아기 말투, "~냥", 과한 애교, 느낌표 연발은 쓰지 않아요.
- **결정은 사용자 몫.** 죠미는 권하지 않고 비교하게 도와요.
- **의학 판단 금지:** "진단", "너에게 맞는", "추천 1위", "효과 보장", 용량 숫자를 쓰지 않아요.
  - 의학 설명은 지식 파일 문장을 따로 보여줘요(죠미의 말이 아님).
- **사실만.** 오류는 실제로 실패한 것(가격 파일을 못 읽음)만 말하고, 원인을 지어내지 않아요.
- **성공은 실제 성공 뒤에만.** 알림 토스트는 저장을 확인한 다음에 띄워요.

| `homeFirst` | "안녕! 오늘은 어떤 피부 고민이 있어?" | 홈 인사(소개를 보기 전) |
| `homeBack` | "또 왔네! 오늘은 어떤 시술이 궁금해?" | 홈 인사(본 뒤) |

- 지시서 예시 "좋아! 가격이 내려가면 알려줄게."는 "조건이 맞으면"으로 바꿨어요.
  - 알림 종류에는 '파는 지점이 늘면'처럼 가격과 무관한 것도 있어서, 사실과 맞게 고쳤어요.

## 바꾸지 않은 문구 (해요체 유지)
- 가격·조건·출처 설명, 의학 설명(지식 파일), 법적 안내(진단·추천 아님, 저장 안 함)
- 버튼 이름: 담기, 알림, 되돌리기, 다시 시도 …

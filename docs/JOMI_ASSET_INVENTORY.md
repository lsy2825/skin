## 2. 앱에서 쓰는 그림 (원본에서 잘라내기만 함)
`python3 brand/make_expressions.py`가 표정 시트에서 만들어요. 다시 그리거나 생성한 부분이 없어요.
- 시트의 이름표·설명 글자 줄(y 403–520, 884–1024)은 지우고 그림만 잘라요.
- 전신 그림은 모든 표정을 **같은 배율**(시트 400px → 360px)로, 같은 바닥선에 세워요. 그래서 표정을 바꿔도 크기가 튀지 않아요.

| 파일 | 크기 | 쓰는 곳 | 대체 텍스트 |
|---|---|---|---|
| `app/assets/jomi/expr-<표정>-96.webp` ×8 | 96×96, 4–6 KB, 원형·투명 | 상단 바, 홈 인사, 말풍선, 토스트, 로딩 | `""`(옆에 글이 있음) |
| `app/assets/jomi/expr-<표정>-360.webp` ×8 | 360×360, 16–25 KB, 투명 | 소개 시트, 빈 화면 | 소개 시트: "윤실장 공식 안내냥 죠미", 빈 화면: `""` |
| `app/assets/jomi/expr-default-160.png` | 160×160, 41 KB, 원형·투명 | PIN 화면(76px) | `""` |

- 얼굴 원 뒤의 색은 CSS(`.mascot`의 `--butter-soft`)가 칠해요. 밝은 화면은 연한 노랑, 어두운 화면은 짙은 갈색이에요.
- **품질 확인**(화면 캡처로 직접 봄, 밝은·어두운 화면, 390px)
  - PIN, 상단 바, 홈 인사, 첫 소개, 빈 장바구니, 관심 없음, 쉬운 용어, 피부 고민 가이드에서 얼굴이 잘리지 않고 알아볼 수 있어요.
  - 시무룩한 표정의 회색 소용돌이는 어두운 화면에서 대비가 낮아요. 장식이고 글이 함께 있어서 그대로 뒀어요.
- **예전 그림(되돌릴 때를 위해 남겨 둠):** `jomi-face-96.webp`, `jomi-face-160.png`, `jomi-portrait-360.webp`
  - 앱 아이콘 원본에서 자른 것(`brand/make_mascot.py`)이에요. 2026-10-14부터 화면에서는 쓰지 않아요.
  - `jomi.js`의 `files` 세 줄만 바꾸면 돌아가요.

## 3. 표정 세트 — 상태
| ID | 이름 | 시트 이름 | 쓰는 곳 | 상태 |
|---|---|---|---|---|
| 01 | default | 기본 미소 조미 | 상단 바, PIN, 홈 인사, 다시 방문 소개 | ✅ 시트 |
| 02 | welcome | 자기소개 조미 | 첫 자기소개 | ✅ 시트 |
| 03 | curious | 궁금한 조미 | 피부 고민 가이드(묻기·머리말) | ✅ 시트 |
| 04 | thinking | 생각하는 조미 | 피부 고민 가이드가 찾은 정보를 보여줄 때 | ✅ 시트 |
| 05 | explaining | (시트에 없음) 안경 쓴 설명 표정 | 시술 사전, 쉬운 용어 | ⏳ 그림 필요 → 지금은 자기소개 표정 |
| 06 | happy | 신나는 조미 | 담기·저장 완료 | ✅ 시트. 시트의 '최저가 발견'에는 쓰지 않아요(② 객관 표시) |
| 07 | wink | 윙크하는 조미 | 가격 알림 저장 | ✅ 시트 |
| 08 | empty | 시무룩한 조미 | 검색 결과 없음, 관심 없음, 고민을 찾지 못함 | ✅ 시트 |
| 09 | cart | (시트에 없음) 장바구니를 든 표정 | 빈 장바구니, 빈 비교함 | ⏳ 그림 필요 → 지금은 기본 미소 |
| 10 | sleeping | 졸린 조미 | 로딩 | ✅ 시트 |
| 11 | error | (시트에 없음) 곤란한 표정 | 오류 복구 | ⏳ 그림 필요 → 지금은 시무룩 |

- 화면 코드는 표정 ID로 그림을 불러요(`jomiImg("cart", …)`). 그림이 없는 표정은 레지스트리의 `fallback` 표정을 보여줘요.
- `tests/e2e/jomi.js`가 확인해요: 승인된 표정 8개가 각자 그림을 갖는지, 나머지는 그림이 있는 대신 표정을 가리키는지, 화면에 레지스트리 밖 그림이 없는지, 로딩·검색 결과 없음·고민 가이드·알림 토스트가 맞는 표정인지.

**표정 그림을 추가하는 방법**
1. 그림을 받아요. 권장: 지금 시트와 같은 화풍·크기, 투명 배경.
2. 시트라면 `brand/`에 원본 그대로 넣고, `make_expressions.py`의 `SHEET`에 칸·머리 위치를 적어요.
3. `app/jomi.js`에서 그 표정에 `...E("<id>")`를 넣고 `art: "approved"`로 바꿔요. `app/sw.js`의 SHELL에도 추가해요.
4. 아래 '품질 기준'을 확인하고 `tests/e2e/jomi.js`를 돌려요.

**사용자에게 필요한 것**
- 시트에 없는 표정 3종: 안경 쓴 설명(explaining), 장바구니를 든(cart), 곤란한(error)
- 이름 확인: 시트의 이름표는 **'조미'**, 앱은 **'죠미'**예요. 어느 쪽이 맞는지 알려 주세요.
- 목걸이 확인: 앱 아이콘 원본은 하트 펜던트, 표정 시트는 'ㅈ' 동전이에요. 앱 아이콘을 시트에 맞출지 결정이 필요해요(지금은 둘 다 그대로).

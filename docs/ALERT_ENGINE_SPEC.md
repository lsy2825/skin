# 가격 알림 엔진 명세 (Alert Engine)

기준일: 2026-10-14. 코드: `app/domain/intel.js`(`evalAlert`·`evalWatch`·`WATCH_T`), `app/app.js`의 `watchNow`·`checkAlerts`·`alertSheet`·`alertsCard`·`notifyPanel`. 테스트: `tests/intel.test.js`(지켜보기 6개 포함), `tests/e2e/pricenow.js` S16~S18, `tests/e2e/jomi.js`(알림 저장 토스트).

## 1. 알림 종류
| 종류 | 대상 | 이번 작업 |
|---|---|---|
| **지켜보기** (watch) | 시술(비교 키) | 새로 만듦. 아래 6가지 변화를 한 알림에서 켜고 끔 |
| 목표가 이하 · 새 최저가 · 파는 지점이 늘면 | 시술 | 그대로(값 계산 방식만 고침, §3) |
| 장바구니 합계 | 장바구니 | 그대로 |
| 이벤트 종료 3일 전 · 목표가 | 특정 가격 | 그대로 |

### 지켜보기의 변화 6가지 (지시서 9.2)
| 변화 | 언제 알림 | 기록에 남는 값 |
|---|---|---|
| 가격 하락 | 최저가가 지난번 관측보다 낮아짐 | 이전·새 최저가, 새 최저가 지점 |
| 목표가 이하 | 최저가가 목표가 이하로 **내려간 그때 한 번**(계속 아래면 다시 안 울림) | 이전·새 값 |
| 최저가 지점 변경 | 가장 싼 지점이 다른 곳으로 바뀜(같은 값으로 공동인 경우는 제외) | 이전 지점 → 새 지점, 이전·새 가격 |
| 새 비교 가능 지점 | 이 시술을 파는 지점이 새로 생김 | 이전·새 지점 수, 새 지점 |
| 최저가 이벤트 종료 | 지난번 최저가였던 가격이 기간 종료 또는 가격표에서 빠짐 | 그 지점, 이전 가격 |
| 재확인 필요 | 최저가 지점의 이번 주 수집이 실패해 지난 자료임 | 지점, 이유 |

## 2. 관측 규칙
- **실제 관측끼리만 비교해요.** 기준(base)은 알림을 만든 순간의 값이고, 앱을 열 때마다 지금 값과 비교한 뒤 기준을 지금 값으로 바꿔요. 같은 관측으로는 다시 울리지 않아요.
- 처음 만들 때는 기준만 정하고 아무것도 울리지 않아요.
- 데이터가 매주 바뀌어서 실제 변화는 갱신 뒤 처음 앱을 열 때 보여요. 기록의 '관측 YYYY-MM-DD'는 데이터 수집일이에요.
- 지켜보기를 만들면, 그 시술의 **지난주 실제 변동**(빌드가 남긴 `changes`)을 '지난 기록'으로 알림 기록에 넣어요(알림이 울린 건 아니라고 표시).

## 3. 값의 기준 (화면 설정과 분리)
- 값은 **병원 표시가**(VAT 표시 전)예요.
- 지역은 알림을 만든 때의 지역을 저장해서 써요.
- 브랜드는 모든 브랜드, 특가 포함 여부는 만든 때 설정을 따라요.
- **결함 수정:** 예전 알림은 화면의 가격(부가세 포함 예상가, 지금 지역·브랜드 필터)을 썼어요.
  - 그래서 부가세 표시를 바꾸거나 지역을 바꾸면 '새 최저가'가 잘못 울릴 수 있었어요.
  - 2026-10-14 전에 만든 알림은 처음 한 번 **조용히 기준을 다시 잡아요**(울리지 않음).

## 4. 알림 기록 (지시서 9.3)
`pc:notes`(이 휴대폰, 30개)에 구조화해서 저장해요.
- 항목: `{at, obs, type, k, name, b, before, after, text, read, past?}`
- 화면에는 종류 배지, 시술명, 실제 지점, 이전 → 새 가격, 관측일, **가격 보기**(그 시술 비교 화면)가 나와요.
- '기록 지우기'를 누르면 되돌리기도 할 수 있어요.

## 5. 휴대폰 알림 (지시서 9.4·10.4)
| 상황 | 화면 |
|---|---|
| 지원 안 함 | "이 브라우저는 웹 알림을 지원하지 않아요" |
| iPhone·iPad(설치 전) | "홈 화면에 설치한 앱에서만(iOS 16.4+)" + 설치 방법 |
| 아직 안 켬 | '휴대폰 알림 켜기' — **누를 때만** 권한을 물어요 |
| 켜짐 | 앱을 열 때 찾은 변화를 휴대폰 알림으로도 보여줌 + '테스트 알림 보내기 (TEST)' |
| 꺼짐(거부) | 브라우저 설정에서 바꾸라는 안내 |

- 테스트 알림은 제목이 "[TEST] 윤실장 알림 시험"이고, 기록에도 TEST 배지가 붙어요.
- **앱이 닫혀 있을 때 오는 푸시는 없어요(BACKEND_REQUIRED).** 화면에도 그렇게 적었어요.
  - 하려면 푸시 서버, VAPID 키, 구독 저장소(예: Supabase `push_subscriptions` + 정책), 서버 쪽 비교 작업이 필요해요.

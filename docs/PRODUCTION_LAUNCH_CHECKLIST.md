## 2. 법률·정책 (NEEDS_LEGAL_REVIEW)

- [ ] 이용약관·환불 정책(`CREDIT_REFUND_POLICY_SPEC.md` 초안) 확정, 결제 화면 고지

- [ ] 선불 크레딧의 법적 성격(선불전자지급수단 해당 여부) 확인
- [ ] 개인정보 처리방침: 사진 분석(국외 AI 사업자 전송 여부), 결제 정보, 푸시

- [ ] 미성년자 결제 대응
- [ ] 세금계산·부가세 신고 방식(부가세 포함 표시 가격)

# 유료 결과의 '쓸모' 기준과 차감 정책 (2차 검토 R05)

크레딧은 **쓸모 있는 결과**가 나왔을 때만 차감해요. 판정은 `app/domain/premium.js usable()` 하나이고, 앱(시연 지갑)과 서버(`server/src/jobs.mjs`)가 같은 함수를 써요.

| 결과 종류 | 쓸모 있음(차감) | 쓸모 없음(미차감) |
|---|---|---|
| 이벤트 글 읽기 / 견적 읽기 | 올바르게 읽힌 항목 중 **정확히 같은 묶음**에 맞고, 3곳 이상과 시장 비교가 된 항목이 1개 이상 | 가격 줄만 읽힘, 비슷한 묶음·후보 여러 개·못 찾음뿐, 비교 지점 3곳 미만 |
| 여러 이벤트 비교 | **서로 다른 2개 이상 이벤트**에 같은 정확 묶음이 있음 | 입력 1개, 공통 묶음 0개, 잘못 읽힌 항목뿐 |
| 장바구니 계획 | A·B·C 계획 중 합계가 계산된 계획 1개 이상 | 모든 계획 합계가 없음(가격 없는 시술·2회차 가격 없음 포함) |
| 지역 보고서 | 지점 3곳 이상인 지역이 2개 이상 | 그 미만 |
| 가격 이력 | 서로 다른 8주 · 49일 · 공백 2주 이하 · 관측마다 5곳 이상 | 그 밖(예: 4일 연속 관측 = 1주) |
| 제품 비교 | 두 시술 모두 가격 있음 | 한쪽이라도 없음 |
| 종합 | 모든 부분이 각각 쓸모 있음 | 하나라도 아님 |

**순서:** 무료 사전 확인(`available`) → 예약 → 결과 만들기 → `usable`이면 차감, 아니면 예약 반환.

**쓸모 없는 결과의 처리(정책):** 크레딧은 돌려주고, 읽은 내용은 **무료 미리보기**로 그 자리에서 보여줘요(저장하지 않음). 이유: 사용자가 붙여 넣은 글이 어떻게 읽혔는지 보면 글을 고쳐 다시 시도할 수 있고, 돈은 들지 않아요. 미리보기를 보고 다시 실행하면 새 예약이에요.

시험: `tests/round2.test.js`(R05), `server/test/round2.test.mjs`, 기존 `server/test/api.test.mjs`.

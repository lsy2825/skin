# 브랜드별 가격 비교

기준일: 2026-10-14. 코드: `app/app.js`의 `brandCard`·`brandSheet`(시술별 비교 화면). 테스트: `tests/e2e/pricenow.js` S12, `tests/e2e/objective.js`(플래그).

## 1. 무엇을 보여주나
시술별 비교 화면(같은 비교 키 = 같은 시술·용량·회차·원산지)에서, 데이터에 있는 브랜드마다 카드 하나:
| 항목 | 계산 |
|---|---|
| 지점 수 | 지금 지역·브랜드 설정에서 이 시술 가격이 있는 그 브랜드 지점 |
| 가격 범위 | 지점마다 가장 싼 가격 하나씩 모았을 때 최저~최고 |
| 중간값 | 같은 목록의 가운데 값 |
| 조건부 가격 | 그 지점들 중 대표 가격이 조건부(체험가·한정가·첫 방문·시간 조건)인 곳 수. 없으면 "모두 조건 없는 가격" |
| 마지막 확인 | 그 브랜드 지점 중 가장 최근 수집일 |
| 표본 적음 | 지점이 3곳 미만이면 표시 |

- 브랜드는 데이터(`meta.brands`)에서 동적으로 만들어요. 지금 4개(블리비·쁨·톡스앤필·리엔장)이고, 포에버는 수집을 멈춰서 지점이 없어요.
- 안내 문구: "지점 수가 다르면 브랜드끼리 바로 견주기 어려워요." 브랜드 하나를 일반화하지 않아요.
- 부가세 표시는 화면 설정(부가세 포함 예상가 / 병원 표시가)을 따라요.

## 2. 지점 목록으로 연결
카드를 누르면 그 브랜드 지점들의 **같은 비교 키** 가격 목록 창이 열려요.
- 지점, 가격, 상품명, 조건 배지, 확인일, '가격 근거', '지점'.
- 순서: 지역·이름순(기본).
- 테스트에서 이 창의 가격이 같은 화면 '지점별 가격' 목록의 가격과 지점마다 같은지 확인해요. 서로 다르면 실패예요.
- 예전 연결(전체 가격표에서 시술 이름으로 검색)은 이름 검색이라 정확하지 않아서 바꿨어요.

## 3. ② 객관 표시와 플래그
| | 기본(`lowestHighlight: false`) | 플래그를 켜면 |
|---|---|---|
| 카드 순서 | 브랜드 순서 고정 | 최저가 낮은 순 |
| 큰 숫자 | 가격 범위 | 브랜드 최저가 |
| 지점 이름 | 없음 | 최저가 지점 + 브랜드 간 차액, "브랜드 중 최저" |
| 지점 목록 순서 | 지역·이름순 | 낮은 가격순 |

지시서 7.2의 "검색한 시술의 최저가 · 해당 지점"은 사용자 지시 ②("②를 유지") 때문에 기본으로 켜지 않았어요. 최저가 숫자는 범위의 왼쪽 값으로 보여요. 법률 검토 뒤 `app/config.js`의 플래그 하나로 켤 수 있어요.

## 4. 검색 결과에는 넣지 않은 이유
참고 사이트는 검색 결과 옆에 '브랜드별 최저'를 둬요. 윤실장의 검색 결과는 이름 검색이라 용량·회차가 섞여요(예: '보톡스'). 규격이 다른 가격의 브랜드 최저를 보여주면 지시서 6.4(다른 조건을 같은 조건처럼 비교하지 않기)에 어긋나요. 그래서 같은 비교 키로 묶인 시술별 비교 화면에만 둬요.

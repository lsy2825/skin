# 시연 단계 기능 (DEMO-FIRST)

기준일: 2026-10-14. "YOONSILJANG — DEMO-FIRST PRODUCT EXPERIENCE EXPANSION" 지시서의 15개 기능을 정리했어요.
- **원칙:** 모든 기능은 실제 가격 데이터(`app/data.json`)로 이 휴대폰 안에서 실제로 움직여요. 서버로 보내는 건 버튼에 그렇게 적힌 것('GitHub로 신고')뿐이에요.
- **지어내지 않은 것:** 가짜 가격, 가짜 가격 이력·변동, 가짜 계정, 성공한 척하는 서버 접수는 없어요.
- **② 유지:** 사용자 지시("②를 유지")대로, 새 기능도 특정 병원을 '최저가'로 앞세우지 않아요. 여러 지점을 맞댈 때 차액은 **사용자가 정한 기준 지점**(비교함 맨 위)과의 차이로 보여줘요. A/B 비교와 같은 방식이에요.
- 확인: `tests/e2e/demo_features.js`, `tests/spec.test.js` (결과는 `QA_REPORT.md`)

## 1. 먼저 확인한 기존 기능 (중복 조사)
| 지시서 기능 | 이미 있던 것 | 이번에 한 것 |
|---|---|---|
| 1·7 빠른 비교·비교함 | A/B 지점 비교(2곳), 시술별 비교(전 지점) | 2~4곳 비교함과 '빠른 비교' 화면(새로) |
| 2 시술 규격 | 비교 기준 이름, 시술 사전, '보톡스 종류' 안내 | 이름에서 제품·원산지·용량·샷·횟수·부위를 읽는 `domain/spec.js`(새로) |
| 3 조건 요약 | 가격 근거 시트의 긴 설명, 배지 | 5줄 요약(조건 있음·제한 없음·미확인)(새로) |
| 4 비교 저장 | 없음 | 새로 |
| 5 즉시 갱신 | 필터·정렬·지역이 바로 다시 그려지고 주소에 남음 | 목록 ↔ 분포 그래프 강조 연결, 빠른 비교 주소(`#quick?k=`) |
| 6 쉬운 용어 | 시술 사전(시술 이름) | 가격·단위 용어 18개(`app/terms.js`)와 `#terms` 화면(새로) |
| 8 방문 전 체크리스트 | 비교 화면 '가격과 함께 꼭 확인하세요' 카드 | 체크해서 저장하는 질문 목록(새로) |
| 9 제공 시술 표 | 장바구니 병원별 견적(지점마다 '없음' 표시) | 담은 시술 × 비교함 지점 표(새로) |
| 10 가격 확인 요청 | 가격 오류 신고(GitHub·복사) | 원본 주소 표시, '기기에만 저장(시연)' 추가, 보낸 방식별 상태 |
| 11 관심 대시보드 | 관심 탭(하트) — **'최저가 · 병원 이름'이 남아 있었음** | 중간값·범위·지점 수·변화·확인일로 바꿈 |
| 12 비교 보고서 | 장바구니 견적 복사, 비교 요약 복사 | 지점별 총액·기준 대비 차액·조건·작성 시각 보고서(새로) |
| 13 지역별 가격 | 없음(지역 선택 필터만) | 새로 |
| 14 업데이트 소식 | 가격 변동 화면(전체) | 관심 시술만, 실제 기록만(새로) |
| 15 죠미 설정 | 기기 '동작 줄이기'만 따름 | 안내 빈도·움직임·설명 길이(새로) |

## 2. 기능별 동작
| # | 기능 | 어디서 | 동작 | 저장 |
|---|---|---|---|---|
| 1 | 빠른 비교 | 탐색 → '빠른 비교', 비교 화면 '비교 도구' | 비교함의 2~4곳을 같은 비교 키(용량·회차·원산지가 같은 것)로 맞대요. 실제 지점 이름, 가격, 막대(같은 눈금), 기준 대비 차액, 조건 배지, 확인일·출처. 같은 사양이 없는 지점은 '비교 불가'와 그 지점의 비슷한 규격(무엇이 달라 비교하지 않는지) | 주소 `#quick?k=` |
| 2 | 시술 규격 확인 | 비교 화면 카드, 가격 근거 시트 | 제품·장비, 원산지, 등급(병원 표기), 용량 또는 샷 수, 횟수, 부위, 성별. 이름에 없으면 '미확인', 횟수 표기가 없으면 '추정'. 같은 제품군의 다른 규격(무엇이 다른지)과 이름이 비슷한 시술, 시술 사전 연결 | — |
| 3 | 가격 적용 조건 | 가격 근거 시트 맨 위, 빠른 비교 줄 | 첫 방문 · 체험 가격 · 부가세 · 기간 · 그 밖의 조건. 상태: 조건 있음 / 제한 없음 / 미확인(표기 없음) | — |
| 4 | 비교 저장 | 비교 도구 '이 비교 저장', 빠른 비교, 보고서 '보관' | 저장 시각, 데이터 날짜, 지점별 병원 표시가·부가세 표기·확인일을 보관. `#snap/<id>`에서 '저장 시점'과 '지금'을 나란히(같은 부가세 방식으로). 데이터가 갱신되지 않았으면 그렇다고 적어요 | 기기 `pc:snaps`(20개) |
| 5 | 즉시 갱신 | 비교·빠른 비교 | 시술·규격·정렬·지역·지점을 바꾸면 그 자리에서 다시 계산. 목록 줄에 올리면 분포 그래프의 같은 지점 점이 강조되고, 그래프에서 점을 고르면 목록 줄이 강조돼요 | 주소 |
| 6 | 쉬운 용어 | 탐색 → '쉬운 용어', 조건·규격 옆 '?' | 짧은 설명 + '조금 더'. 가격 용어는 "윤실장의 설명(의학 정보 아님)", 단위·시술 용어는 "일반적인 뜻(의료진 검수 전)". 나에게 맞는지·얼마나 필요한지는 말하지 않아요 | — |
| 7 | 비교함 | 비교 카드 보기, 가격 근거, 지점 화면, 빠른 비교 | 최대 4곳. 빼기(되돌리기), 바꾸기, 추가, '기준으로'(맨 위로) | 기기 `pc:short` |
| 8 | 방문 전 체크리스트 | 비교 도구, 가격 근거, 빠른 비교 | 가격 포함 범위, 부가세(그 가격의 표기에 맞춰), 가격 조건, 기간, 시술 규격(미확인 항목은 물어볼 질문으로), 의료진에게 물을 것. 진행률, 복사 | 기기 `pc:checks` |
| 9 | 지점별 제공 시술 | 빠른 비교 아래 | 장바구니 시술 × 비교함 지점. 값 = 장바구니와 같은 계산(수량·첫 방문가 1개). '없음'(가격표에 없음)·'확인 안 됨'(그 주 수집 실패)은 0원으로 치지 않고 합계에서 빼요 | — |
| 10 | 가격 확인 요청 | 가격 근거 → '원본과 달라요' | 원본 주소·사유·메모. '기기에만 저장(시연)' = 서버로 안 감, '내용 복사' = 직접 보내야 함, 'GitHub로 신고(실제 접수)' = 공개 이슈 화면(제출은 GitHub에서). 관심 탭에 방식별 상태 | 기기 `pc:reports` |

| 12 | 비교 보고서 | 빠른 비교 '비교 보고서' | 장바구니가 있으면 시술·수량·지점별 예상 총액·기준 대비 차액·조건부 가격 수·없는 시술, 없으면 한 시술의 지점별 가격·조건. 작성 시각·데이터 날짜. 복사·공유·보관 | 보관 시 `pc:snaps` |
| 13 | 지역별 가격 | 비교 화면 | 시·도별 지점 수·범위·중간값(조건 없는 가격, 전국, 브랜드 필터 적용). 3곳 미만은 '표본 적음'과 안내 | — |
| 14 | 업데이트 소식 | 관심 탭 | 매주 수집에서 실제로 바뀐 관심 시술 가격(`data.json` changes)만. 첫 기록이면 빈 상태와 다음 갱신 안내 | — |

## 3. 시연과 정식 연동의 구분
| 항목 | 지금(시연) | 정식 출시 때 |
|---|---|---|
| 접근 | PIN 화면 그대로 | 실제 인증 또는 공개로 결정(`RELEASE_CHECKLIST.md`) |
| 로그인 | 연결 안 됨. 마이에 "계정 연결은 정식 출시 때 열려요"와 준비된 것만 표시(작동하는 척하는 버튼 없음) | 카카오·Google·Apple(Supabase OAuth). 화면 배치·`app/auth.js`·동기화 코드·DB 정책은 준비됨, 키 필요(`docs/로그인_설정.md`) |
| 회원가입·약관 동의 | 없음 | 정식 출시 때 |
| 비교함·저장·체크리스트·설정 | 이 휴대폰에만 | 로그인 뒤 계정 동기화(설계됨) |
| 가격 확인 요청 | 기기 저장(시연) / 복사 / GitHub 공개 이슈 | 운영 큐(Supabase `user_reports`, 관리자 인증) |

## 4. 한계
- 규격은 상품명과 비교 기준 이름에서만 읽어요. 병원이 이름에 적지 않은 제품·용량은 알 수 없어요('미확인').
- 조건 요약도 상품명·종류·태그·부가세 표기·종료일에서만 읽어요. 병원 공통 안내(1인 1회, 최소 결제)는 수집하지 않아요.
- 지역별 가격은 지점 수가 적은 지역이 많아요. 통계로 읽지 말라고 표시해요.
- 업데이트 소식·관심 시술 변화는 매주 수집이 쌓여야 의미가 생겨요(첫 기록 2026-10-13).
- 용어 설명은 의료진 검수 전이에요.

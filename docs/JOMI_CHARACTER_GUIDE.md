# 죠미(Jomi) 캐릭터 가이드

기준일: 2026-10-14. 윤실장 공식 안내 캐릭터의 정체성과 쓰는 규칙이에요.
- 그림 파일과 상태: `JOMI_ASSET_INVENTORY.md`
- 동작: `JOMI_INTERACTION_SPEC.md`
- 대사: `JOMI_COPYWRITING.md`
- 코드: `app/jomi.js`(레지스트리·대사), `app/app.js`의 `jomiImg`·`jomiSay`·`jomiEmpty`·`jomiToast`·`jomiSheet`

## 1. 기본 설정
| 항목 | 내용 |
|---|---|
| 이름 | 죠미 (Jomi) |
| 종 | 샴고양이 |
| 역할 | 윤실장 공식 안내냥 · 피부시술 정보 도우미 |
| 하는 일 | 어려운 시술 이름을 쉽게 풀어 주고, 같은 조건끼리 병원별 가격을 비교하도록 안내해요 |
| 하지 않는 일 | 진단, 개인에게 맞는 시술 판단, 용량 결정, 효과 보장, 특정 병원 추천. 죠미는 의료진이 아니에요 |

## 2. 성격과 말투
- 친절하고 다정해요. 호기심이 많고, 설명을 잘해요.
- 살짝 새침하고 장난기가 있어요(숨은 재미: 소개 시트에서 죠미를 누르면 한마디).
- 결정을 강요하지 않아요. "비교는 내가, 결정은 네가!"
- 말투: 짧은 반말("~해 줄게", "~볼까?").
  - 아기 말투, 과한 애교, 느낌표 연발은 쓰지 않아요.
- 앱의 안내문·의학 설명은 지금처럼 해요체로 남겨요.
  - 죠미가 말하는 줄(말풍선·토스트·빈 화면 제목)만 반말이에요.
  - 의학 문장은 죠미가 말하지 않고, 지식 파일 문장 그대로 보여줘요.

## 3. 공식 원본 (사용자가 준 그림 2장)
두 파일 모두 덮어쓰지 않아요. 앱의 죠미 그림은 모두 이 두 파일에서 **잘라내기만** 했어요(다시 그리거나 생성한 부분 없음).

**① 앱 아이콘 원본** — `brand/yoonsiljang-icon-original.webp`
- 1254×1254, 사용자 제공, SHA-256 `c5852a78…ad3c1`
- 포즈와 표정이 하나뿐이에요: 윙크하며 웃는 얼굴, 두 앞발을 '윤실장' 글자 위에 올림.
- 지금은 **앱 아이콘(홈 화면 아이콘·파비콘)**에만 써요. 2026-10-14까지는 앱 안 그림도 이 파일에서 잘랐어요(`jomi-face-*`, 되돌릴 때를 위해 남겨 둠).

**② 표정 시트 원본** — `brand/jomi-expressions-original.webp` (2026-10-14 사용자 제공)
- 1536×1024, 투명 배경, SHA-256 `16c6299e…a4dfc9`
- 표정 8개와 시트에 적힌 쓰임새:

| 시트 이름 | 시트의 쓰임새 | 앱 표정 ID | 앱에서 쓰는 곳 |
|---|---|---|---|
| 기본 미소 조미 | 홈 화면, 기본 상태 | default | 상단 바, PIN 화면, 홈 인사, 다시 방문 소개 |
| 자기소개 조미 | 캐릭터 프로필, 첫 인사 | welcome | 첫 자기소개 (설명 표정 대신에도 씀) |
| 궁금한 조미 | 피부고민 검색 | curious | 피부 고민 가이드 |
| 생각하는 조미 | AI 정보 탐색, 고민 중 | thinking | 피부 고민 가이드가 찾은 정보를 보여줄 때 |
| 신나는 조미 | 최저가 발견, 성공 상황 | happy | **담기·저장 완료만.** '최저가 발견'에는 쓰지 않아요(② 객관 표시 원칙, `OBJECTIVE_DISPLAY_POLICY.md`) |
| 윙크하는 조미 | 알림 설정 완료, 긍정 피드백 | wink | 가격 알림 저장 |
| 시무룩한 조미 | 검색 결과 없음, 아쉬운 상황 | empty | 검색 결과 없음, 관심 없음 (오류 표정 대신에도 씀) |
| 졸린 조미 | 앱 로딩, 대기 상태 | sleeping | 로딩 |

- **두 원본의 차이**(관찰한 것):
  - 같은 점: 크림·아이보리 몸통과 짙은 갈색 포인트(귀, 얼굴 마스크, 앞발, 꼬리), 파란 눈, 안쪽이 분홍인 큰 귀, 부드러운 3D 털 질감
  - 다른 점: 목걸이 — ①은 분홍 목걸이에 금색 하트 펜던트, ②는 베이지 목걸이에 'ㅈ'이 새겨진 금색 동전
  - 다른 점: 이름 표기 — ②의 이름표는 **'조미'**, 앱과 문서는 **'죠미'**. 어느 쪽이 맞는지 사용자 확인이 필요해요(그때까지 앱은 '죠미' 유지).
- 시트에 없는 표정 3개(안경 쓴 설명·장바구니·곤란함)는 아직 그림이 없어요. 각각 자기소개·기본 미소·시무룩 표정으로 대신 보여줘요(`JOMI_ASSET_INVENTORY.md` §3).
- 글로만 지시해서 같은 캐릭터를 다시 그릴 수 있다고 가정하지 않아요. 비슷한 다른 고양이로 바꿔 넣지도 않아요.

## 4. 쓰는 곳과 밀도
| 화면 | 죠미 | 이유 |
|---|---|---|
| 상단 바 | 작은 얼굴(34px). 누르면 소개 | 브랜드 인사, 어디서나 소개 열기 |
| 홈 | 인사 말풍선 버튼(28px), 소개 시트(128px) | 첫인상. 검색창을 밀어내지 않게 한 줄 크기 |
| 피부 고민 가이드 | 말풍선 아바타(32~44px) | 대화형 정보 안내 |
| 시술 사전 | 한마디 말풍선 1개 | 쉬운 설명의 출발점 |
| 빈 장바구니·검색 결과 없음·관심 없음·데이터 오류 | 빈 화면 그림(88px) 1개 | 다음 행동 안내 |
| 담기·관심 저장·알림 설정 성공 | 토스트 얼굴(28px) | 짧은 확인 |
| 로딩(느릴 때만), PIN 화면 | 얼굴 + 문구(로딩은 졸린 표정) | 기다림 안내 |
| **가격 비교·차트·병원 목록·필터·탭 바** | **넣지 않아요** | 숫자와 비교가 먼저예요. 테스트로 비교 화면에 죠미가 0개인지 확인해요 |

- 한 화면에 죠미는 1~2번까지만 나와요(상단 바 얼굴 제외).
- 죠미는 항상 글과 함께 나와요. 그림만으로 뜻을 전하지 않아요.
- 장식용 그림은 `alt=""`로 두고, 소개 시트의 큰 그림만 "윤실장 공식 안내냥 죠미"라고 읽혀요.

## 5. 하지 말 것
- 사용자가 준 원본 2장과 다른 고양이 그림, 다른 화풍, 다른 눈 색·무늬를 쓰지 않아요.
- 원본을 억지로 벡터(SVG)로 바꾸지 않아요.
- 처음 들어왔을 때 소개 창을 저절로 띄우지 않아요.
- 죠미가 "진단", "추천 1위", "너에게 맞는 시술", "효과 보장"을 말하게 하지 않아요.
- 귀여움 때문에 버튼·가격을 가리거나, 화면을 느리게 만드는 큰 애니메이션을 넣지 않아요.

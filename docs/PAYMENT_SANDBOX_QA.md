## 3. 토스 테스트 키가 생기면 실행할 체크리스트

1. SANDBOX로 서버 배포(test_ 키). `GET /v1/health` → mode SANDBOX.
2. MINI 주문 → 토스 테스트 카드로 결제 → confirm → 지갑 +5, 광고 없는 기간 +7일.
3. 같은 confirm 다시 → already. 토스 개발자센터에서 웹훅 재전송 → 변화 없음.
4. 결제창에서 취소 → 주문 CREATED → 1시간 뒤 대사 EXPIRED.
5. 결제 후 confirm을 일부러 막기 → 10분 뒤 대사가 지급.
6. 관리자 환불(부분 990→495) → 크레딧 비례 회수. 전액 환불 → 광고 없는 기간 제거.
7. 금액을 바꾼 confirm → 409. 다른 계정의 주문 → 404.
8. 모든 결과를 이 문서에 날짜·환경과 함께 기록. 실패는 실패로 적기.

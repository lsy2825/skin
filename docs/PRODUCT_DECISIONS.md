## 2. 중립성 원칙 문구

검토 지적: "병원에게 어떤 돈도 받지 않는다"와 "향후 병원 B2B"를 동시에 약속하면 모순.

- **채택한 문구(앱 '운영 원칙' 화면):** 돈을 받고 비교 순서를 바꾸지 않아요 / 수집 범위·출처·이해관계를 공개해요 / 지금은 병원·제약사·장비 회사에서 받는 돈이 없어요 / 수익 방식이 정해지면 날짜와 함께 적어요.
- **약속하지 않은 것:** "앞으로도 병원 돈은 절대 받지 않음". B2B·광고 여부는 주인이 정할 일이라 열어 둠.
- **주인 결정 필요:** ① 병원 대상 서비스(B2B)를 검토할지, ② 그 경우 이해관계 공개 방식. 결정 전까지 병원 광고·예약 수수료·쿠폰은 만들지 않아요(코드 플래그 `ads`·`booking` false).

## 4. 수집 범위와 데이터 원칙 (DATA)

- 지금 범위(2026-10-14 브랜드 확대 후): 밴스 67 · 블리비 58 · 유앤아이 44 · 닥터에버스 34 · 톡스앤필 32 · 쁨 23 · 데이뷰 14 · 리엔장 5 = **277곳(8개 체인)**. 홈 첫 줄과 '운영 원칙' 화면은 데이터에서 자동으로 적어요(`coverageLine`). "전국 최저가" 같은 표현은 쓰지 않아요.
- 확대 기준(사용자 선택 "공장형 5곳"): 지점이 여럿이고 같은 사이트 틀을 쓰며, robots.txt가 가격 페이지를 허용하고, 가격이 글자로 있고, 로그인 없이 보이는 곳. 탐색 판정은 `docs/DATA_AND_LEGAL.md` §1. 셀린은 표본 부족으로 보류, 오라클·고운세상은 범위 밖(지점마다 형식이 다르거나 가격표가 그림).
- 수집기는 자기 이름을 밝혀요(`YoonSiljangBot/1.0`, 예전엔 Chrome 브라우저 문자열). robots.txt를 지키고, 막히면 다른 이름으로 다시 시도하지 않아요. 이 변경으로 어떤 사이트가 수집을 거절하면, 그 체인은 이전 자료를 유지하고 사람이 검토해요(주간 가드).
- 심평원 비급여 API: **확인 불가(키 없음).** 질의 방법과 최소 검증 절차만 `docs/DATA_AND_LEGAL.md`에 적었어요. 쓸 수 있는지 확인되기 전에는 연동을 만들지 않아요.

## 5. 비용 모델 (BIZ02)과 병원 B2B (BIZ03)

**BIZ02 — 가정 계산이에요. 예상 실적이 아니에요.**

| 가정 | 값 |
|---|---|
| 월 사용자(MAU) | 10,000 |
| 결제자 비율 | 2% |
| 결제자 1명의 월 결제액 | 2,000원 |
| 월 총 결제액 | 400,000원 |
| 부가세 포함 가격으로 보고 1.1로 나눔 | 363,636원 |
| 웹 PG 수수료 3.3% (총액 기준) | −13,200원 |
| **남는 금액** | **≈ 350,436원 — 이익이 아님** |

계산을 다시 해서 검토 패키지의 숫자와 맞는지 확인했어요(400,000/1.1 − 400,000×0.033 = 350,436.4). 이 금액에서 다음이 더 빠져요: 환불, AI 호출비(지금 꺼짐), 서버(Workers 유료 요금제가 필요할 수 있음 — D2), Supabase, 수집·검수 인건비, 고객 지원. 스토어 결제에는 웹 PG 3.3%가 아니라 각 스토어 수수료를 따로 적용해야 해요(요율은 계약·프로그램마다 달라 여기 적지 않음 — 제출 시 확인).

**결론을 보류해요.** "사업이 안 된다"도, "B2B 가능성이 가장 크다"도 이 계산으로는 말할 수 없어요. 판단에 필요한 실측: 결제 전환율 · 재구매 · 건당 비용 · 환불률 · 유지율. 이 값은 실결제 소규모 시험(주인 승인 후)에서만 나와요.

**BIZ03 — 이번에 만들지 않았어요.**
- 병원 광고·예약 건당 수수료·쿠폰은 활성화하지 않음(플래그 off).
- 개인의 고민·사진·장바구니는 팔지 않아요. 집계 정보도 재식별·계약·경쟁법 검토 전에는 내보내지 않아요.
- B2B 검토 순서(제안): 수집 범위가 대표성을 갖춘 뒤 → 병원 인터뷰 → 법률 검토(LEG01) → 이해관계 공개 방식 결정. 정액 광고가 자동으로 합법이라고 보지 않아요.

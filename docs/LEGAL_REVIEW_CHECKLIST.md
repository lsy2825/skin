## 0. 지금 상태 요약
- 배포: 비밀번호 화면 뒤의 비공개 베타예요. 검색엔진에는 노출하지 않아요(`noindex`, `publicIndex: false`). 그래도 데이터 파일과 저장소는 공개 주소에 있어요.
- 수익 모델: 없어요. 광고·협찬·예약·결제·수수료·병원 제휴 모두 없어요(`ads: false`, `booking: false`).
- 사용자 데이터: 각자 휴대폰에만 저장돼요. 서버 수집은 없어요(로그인 꺼짐).

### A. 의료광고 해당 여부 (의료법 제56조·제57조 등, 확인 필요)

2. '최저가', '중간보다 N% 싸요', '초저가' 같은 강조 표현이 문제가 되나요? 병원이 붙인 '체험가·한정가·첫 방문가'를 그대로 옮겨 보여주는 것은요?
3. 시술 설명(지식 베이스)이 특정 시술의 광고로 볼 수 있나요? 효과 표현과 비교 표현은 어디까지 허용되나요?
4. 의료광고 사전심의 대상이 될 수 있는 구성이 있나요?

2. 고민 화면에서 사용자가 직접 누르는 '○○ 가격 →' 버튼(`concernPriceLink`)은 위험을 높이나요?

     - 1~3위·최저가 핀·할인 강조·지점 순위는 플래그로 꺼 뒀어요.
   - 이 정도면 '유인'에 해당하지 않는지, 사용자가 고르는 '낮은 가격순'은 허용되는지 봐 주세요.

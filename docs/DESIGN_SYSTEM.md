## 3. 컴포넌트 (클래스 이름)
- **상단 바** `header.top`: 마스코트, 로고타입(인라인 SVG — 다크 모드 색을 따라감), 기준일·지점 수, 지역 `#regbtn`, 거리 기준 `#locbtn`, 알림 `#notibtn`(읽지 않은 알림 수)
- **탭 바** `nav.tabs`: 5개. 선택 탭은 버터 알약 배경. 900px 이상에서는 왼쪽 세로 레일
- **카드** `.card`(`.flush` 목록용, `.lift` 떠 있는 요약)
- **버튼**: `.btn`(주), `.btn.gray`, `.btn.soft`, `.btn.line`, `.btn.sm`
  - `.linkbtn`: 글자 버튼. 터치 영역 26px 보장
  - `.addbtn`: 담기/담김 — 담긴 상태는 세이지 (2026-10-16 위계 점검 1·21·22)
    - 시술 하나를 담는 버튼(비교 머리글·홈 인기 카드·빠른 비교)은 글자에 규격을 적어요('담기 · 1회'). 옵션 이름이 '기본'뿐인 시술은 시술 이름('담기 · 코 조각주사')을 적어요. 넘치면 말줄임이고, 버튼은 카드 폭을 넘지 않아요(빠른 비교의 긴 패키지 이름도). 320px 홈 카드는 '담기 · '를 숨기고 +/✓와 규격만 보여요('+ 힐러 2cc', 화면 읽기 이름표는 그대로 '담기 · 힐러 2cc — …')
    - 누르면 창 없이 그 규격이 1회로 담겨요. '담김 · 1회'를 다시 누르면 창이 열리는데, 지금 횟수에서 시작하고 횟수·견적·빼기·'n회로 바꾸기'가 먼저 보여요. 같은 시술의 다른 옵션은 그 아래 '다른 옵션 n개'로 접어 둬요. 홈 카드에서는 이름 → 가격 → 담기 순서로 카드 맨 아래에 둬요
    - 가격 줄의 담기(`.item.ra`)는 글자 '담기' 그대로, 화면 읽기 이름표는 '상품 · 지점 내 견적에 담기'. 336px 이상에서는 늘 가격 바로 아래 오른쪽 칸이에요. 320px에서는 배지가 이름·가격 아래 전체 폭을 쓰고, 담기는 배지 마지막 줄 끝 오른쪽에 와요(이름 → 가격 → 조건 → 담기, 배지를 가리지 않음)
    - 담은 뒤 알림은 어느 길로 담아도 같아요: 첫 줄 '내 견적에 담았어요 · 대상 (n개)'(견적이 2개 이상이면 견적 이름), 죠미 말은 둘째 줄. 둘째 줄은 첫 줄을 되풀이하지 않고 다음 할 일·사실만 말해요. 죠미 설정 '끄기'면 첫 줄만 나와요
  - `.favbtn`: 하트(관심)
  - `.tbtn-i`: 원형 아이콘 버튼
- **칩** `.chip`(선택 = 차콜: 켜고 끄는 칩은 `aria-pressed`, 하나만 고르는 칩 묶음은 `role=radio`의 `aria-checked` — 규격 칩 `.vchip`도 같음), `.chip.bchip`(브랜드 필터: 켜짐 = 테두리, 꺼짐 = 점선·흐림), `.seg`(분할 선택)
- **목록** `.item`, `.rank`(1~3위 버터 원), `.disc-row`. 줄 사이는 안쪽 들여 그은 가는 선. 줄 안쪽 여백은 `.item`·`.rank` 모두 14px(글자 시작선 하나, 위계 점검 52). ⓘ 칸(36px)이 있는 줄은 그 칸이 오른쪽 여백(줄 여백 4px)이고, ⓘ가 없는 줄(검색 '종류' 카드에서 설명이 없는 시술)은 14px 그대로라 가격이 가는 선 끝에서 끝나요
- **목록 길이·더 보기** (2026-10-19 위계 점검 5·6·7·8·11·15·16)
  - 더 보기는 `.morelist` 한 모양이에요: '20곳 더 보기 (165곳 남음)', 한 번에 20개(`Stats.more`). 단위 낱말은 목록마다 달라요(지점 '곳', 가격 '개', 종류 '가지'). 누르면 그 자리에 줄을 덧붙이고(`moreList` — 입력한 검색어는 그대로) 새 첫 줄로 초점이 가요. 한 화면에 이런 목록이 둘 이상이면(내 견적의 모두 받을 수 있는 곳·일부만 되는 곳, 검색의 규격·종류·가격) 화면 읽기 이름에 목록 이름을 붙여요('일부만 되는 곳 20곳 더 보기 (53곳 남음)', `name`). 보이는 글자는 같은 모양 그대로예요. 다른 화면으로 가는 '가격 변동 전체 ›'와 줄을 펼치는 '일부만 되는 곳 84곳 보기'도 같은 모양이에요
  - 처음 보이는 줄: 비교 지점 10(가까운순 5), 검색 가격 20(전체 가격표는 100), 지점 가격표 30, 내 견적 병원별 비교 40, 지도 40, 가격 변동·지점 비교 300
  - 지점 가격표 '전체'·카테고리순은 분야마다 소제목 + 처음 5줄 + '○○ N개 모두 보기'예요. 누르면 그 분야 칩이 켜지고, 옆으로 밀리는 칩 줄은 켜진 칩이 보이게 옮기고, 가격표 머리는 위 막대 바로 아래에 와요(분야 칩을 직접 눌러도 칩 줄 위치가 그대로예요). 카테고리순은 분야 안에서 추가 옵션('…1회 추가')을 시술 뒤에 둬요(가격순 정렬은 가격만). 가격의 80% 이상에 같은 종료일이 적혀 있으면 가격표 머리에 한 번만 적고(`Stats.commonDate`), 줄에는 다른 날짜만 남겨요('기간 확인 필요'는 줄마다 그대로)
  - 검색 결과: 검색어에 규격이 있고 맞는 '같은 조건 가격 비교'가 있으면 그것(처음 3개)이 맨 위, 종류는 접혀요(맞는 규격이 없으면 이름만 있을 때처럼 종류가 맨 위). 이름만 있으면 종류(처음 5개)가 맨 위, 규격 바로가기는 접혀요. 용량·샷 수·제품·세부 구분 칩은 '더 좁히기'로 접혀 있다가 하나라도 쓰면 펼쳐져요. 가격 줄의 규격이 섞이면 범위 대신 '여러 규격'과 안내를 적어요(`Stats.sharedKey`)
  - '지역·이름순'의 시·도 순서는 서울 → 경기 → 인천, 그다음 가나다예요(`Stats.sidoCmp`). 위치를 정하지 않았으면 비교 목록 위에 '기준 위치 정하기 → 가까운 5곳'이 있어요. 위치를 정했을 때만 가까운순으로 바뀌고, 그냥 닫으면 정렬은 그대로예요
  - 길이 예산: 핵심 화면(홈·검색 '리쥬란 2cc'·'보톡스'·비교·지점·내 견적 펼침)의 기본 상태는 9장(1장 = 844px, 7±2) 이하예요. 결정 재료 위치는 검색 첫 규격·종류 1장, 첫 가격 줄 2장, 비교 가격 범위 1장, 첫 지점 줄 3장, 지점 첫 가격 2장 안이에요. `tests/e2e/length_budget.js`가 390×844·375×667에서 재고, 넘으면 실패해요

### 같은 역할은 같은 모양 (2026-10-19 위계 점검 묶음 5 · 6.0 규칙 3·4)
- **배지 순서**(29): 어느 가격 줄이든 ① 가격 종류·조건(체험가·한정가·고시가, 첫 방문·평일·시간 한정 …, 버터) → ② 경고(기간 끝남·방문일엔 안 됨·시간 확인 필요·기간 확인 필요·초저가·조건 확인·지난 자료, 코랄) → ③ 정보(~10/31까지·VAT·추가 옵션·고시표·제품·장비, 회색). `kindBadge(r, { warn, info })`가 화면 자기 배지도 같은 자리에 넣어요. 배지 글자는 그대로예요
- **접기 모양**(30): 요약 줄 하나 — 글자(앞 아이콘은 있어도 됨) + 줄 오른쪽 끝의 같은 꺾쇠(CSS 한 개, 펼치면 뒤집힘). 크기만 두 단계: 덩어리 하나인 접기는 카드 한 장에 15/650(비교 '가격 종류별…'·'뭐예요? · 규격 확인', 검색 '비슷한 종류', 고급 비교 설정, 지점 전체 목록 — 줄 접기 상세 필터·더 좁히기·내 설정도 15), 덩어리 안 접기는 13/650 회색(`fold.small`, `minifold`, 검색 팁, 제품 안내). 카드 안에 카드를 넣지 않아요: 덩어리 접기 안의 카드는 테두리를 빼고 가는 선으로 나눠요(`.cmpfold`). 덩어리 접기 위 간격은 화면 간격(16) 그대로
- **가격 근거 ⓘ**(47): 모든 가격 줄(비교·지점 가격표·검색·전체 가격표)의 오른쪽 ⓘ 칸 하나(`infoBtn`, 보이는 칸 36px, 누르는 곳 44px — 오른쪽 카드 여백으로만 넓혀 담기와의 4px는 그대로, 화면 읽기 이름 '… 가격 근거 보기'). 줄에 '가격 근거'·'출처' 글자 링크를 두지 않아요 — 근거 창 '원본' 줄에 병원 원본 링크가 있어요. 검색 줄의 지점명 링크는 남아요
- **버튼 격자**(35): 한 덩어리의 동작 버튼은 같은 폭 2칸 격자(`.bbtns` — 지점 머리 6개, 견적 펼침 끝 4개, 위 16px). 앱 밖으로 나가는 버튼(길찾기·병원 홈페이지)은 글자 뒤 ↗(`outLink`, 새 창). 320px에서는 앞 아이콘을 숨겨 글자가 한 줄에 들어가요
- **가까운 것끼리**: 검색은 필터·결과 두 덩어리(사이 24, 안 8 — '이렇게 찾았어요'는 필터 카드 맨 위, 결과 수·안내 문장은 결과 카드 머리, 32). 지역·이름순 검색 결과는 지점마다 머리 한 번(`.sgh` — 위 24, 첫 줄까지 8로 자기 줄 쪽에 붙임), 다른 정렬은 줄마다 지점 이름(33). 이름이 여러 줄이어도 가격은 첫 줄 기준선(33). 홈 '전체 비교'는 인기 카드 바로 아래 8px, 다음 덩어리는 24px(50)

## 4. 그래프
- **병원별 가격 분포** (`distChart`)
  - 지점 하나 = 점 하나. 겹치면 위로 쌓아요
  - 채운 점 = 조건 없는 가격, 고리 = 조건부, 진한 점 = 지금 보여주는 최저가, 점선 = 중간값
  - 터치·마우스로 툴팁(지점·가격·조건부 여부)을 봐요
  - 키보드: 그래프 상자가 슬라이더예요. ←→로 지점을 옮기고 Enter로 그 지점을 열어요
  - 3곳 미만이면 그리지 않아요
- **가격 이력** (`lineChart`)
  - 축 하나, 2px 선. 단조 3차 보간이라 관측값보다 위아래로 튀지 않아요
  - 기록이 빠진 주는 선을 끊어요. 끝 라벨, 범례, 십자선 툴팁, ←→ 키, '표로 보기'
  - 선은 그려지는 애니메이션이 있어요
  - 지금 실제 기록은 1주(2026-10-13)라 선 없이 "첫 기록"으로 보여줘요
  - 선 모양은 시험용 가짜 데이터(6주, 1주 빠짐)를 브라우저 안에서만 넣어 확인했어요. 배포 데이터에는 넣지 않았어요
- **최저가 발견 막대** (`mrange`): 비교 가능한 가격의 범위 중 최저가 위치(점)와 중간값(세로선)
  - 중간값보다 70% 넘게 낮은 것은 단위가 다른(1샷당·1개당) 경우가 많아서 빼요

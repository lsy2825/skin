- 대비 예: muted/fill 4.89, sage/fill 6.09, coral/fill 5.00(라이트) · muted/fill 5.74, sage/fill 8.33(다크)
- 그래프 색은 dataviz 팔레트 검사기로 라이트·다크 모두 통과했어요.
  - 색맹 시뮬레이션 ΔE 8.4(기준 8 이상), 정상 시각 ΔE 25.2, 바탕 대비 3:1 이상
- 처음 고른 '뮤트 세이지 그래프 색'(#5d8c69)은 채도가 낮아 회색처럼 읽힌다고 검사기에서 떨어졌어요. 그래서 그래프만 조금 더 선명한 녹청을 써요.
- 가격 방향 = 세이지(싸요)·코랄(비싸요). 브랜드 색이라 색만으로 구분하지 않고, 항상 ▼▲·위치·글자와 함께 써요.

**간격·모양·글자**
- 간격: 8pt(4·8·12·16·20·24·32). 화면 좌우 16px, 카드 안 20px
- 모서리: 8·12·16·20(카드)·28(시트)·999(칩)
- 그림자: `--shadow-1`(살짝 뜬 카드), `--shadow-2`(하단 바·시트·툴팁)만
- 글자: Pretendard. 큰 제목 28/760, 제목 19/700, 소제목 16/680, 본문 15/1.55, 보조 13
  - 숫자는 tabular-nums. 큰 가격 38px(비교)·34px(장바구니), 자간 −0.045em
- 움직임: 누름 0.14s, 화면·시트 0.24~0.32s, `cubic-bezier(.2,.8,.2,1)`. `prefers-reduced-motion`이면 전부 꺼져요

## 3. 컴포넌트 (클래스 이름)
- **상단 바** `header.top`: 마스코트, 로고타입(인라인 SVG — 다크 모드 색을 따라감), 기준일·지점 수, 지역 `#regbtn`, 거리 기준 `#locbtn`, 알림 `#notibtn`(읽지 않은 알림 수)
- **탭 바** `nav.tabs`: 5개. 선택 탭은 버터 알약 배경. 900px 이상에서는 왼쪽 세로 레일
- **카드** `.card`(`.flush` 목록용, `.lift` 떠 있는 요약)
- **버튼**: `.btn`(주), `.btn.gray`, `.btn.soft`, `.btn.line`, `.btn.sm`
  - `.linkbtn`: 글자 버튼. 터치 영역 26px 보장
  - `.addbtn`: 담기/담김 — 담긴 상태는 세이지
  - `.favbtn`: 하트(관심)
  - `.tbtn-i`: 원형 아이콘 버튼
- **칩** `.chip`(선택 = 차콜), `.chip.bchip`(브랜드 필터: 켜짐 = 테두리, 꺼짐 = 점선·흐림), `.seg`(분할 선택)
- **목록** `.item`, `.rank`(1~3위 버터 원), `.disc-row`. 줄 사이는 안쪽 들여 그은 가는 선
- **배지** `.k`: 세 가지 톤만 — 중립 `.k4`/`.kt`, 알림 `.k1`/`.k2`(버터), 경고 `.kx`(코랄), 확인 `.k.ok`(세이지)
- **비교 화면**
  - `.pricecard`: 스펙, 현재 최저가, 지점, 상품명·조건·부가세·확인일, 가격 근거·원본·계산 기준, 중간값·최고가·비교 지점 수
  - `.condlow`: 조건부 최저, 확인 필요 초저가
  - `.actions`: 화면 아래 고정 — 알림·지도·복사·담기
- **장바구니** `.ci`(상품 행), `.qty`(수량), `.cartsum`(예상 총액·최저 지점·요약 줄·병원별 비교 버튼·공유·합계 알림)
- **고민 가이드** `.msg.bot` / `.msg.user`(말풍선), `.composer`(아래 고정 입력창), `.infotag`
- **시트·토스트·빈 화면** `.sheet`(위로 올라오는 시트, 손잡이 막대), `.toast`(되돌리기 버튼), `.empty`(아이콘 원 + 제목 + 안내 + 다음 행동)

## 4. 그래프
- **병원별 가격 분포** (`distChart`)
  - 지점 하나 = 점 하나. 겹치면 위로 쌓아요
  - 채운 점 = 조건 없는 가격, 고리 = 조건부, 진한 점 = 지금 보여주는 최저가, 점선 = 중간값
  - 터치·마우스로 툴팁(지점·가격·조건부 여부)을 봐요
  - 키보드: 그래프 상자가 슬라이더예요. ←→로 지점을 옮기고 Enter로 그 지점을 열어요
  - 3곳 미만이면 그리지 않아요
- **가격 이력** (`lineChart`)
  - 축 하나, 2px 선. 단조 3차 보간이라 관측값보다 위아래로 튀지 않아요
  - 기록이 빠진 주는 선을 끊어요. 끝 라벨, 범례, 십자선 툴팁, ←→ 키, '표로 보기'
  - 선은 그려지는 애니메이션이 있어요
  - 지금 실제 기록은 1주(2026-10-13)라 선 없이 "첫 기록"으로 보여줘요
  - 선 모양은 시험용 가짜 데이터(6주, 1주 빠짐)를 브라우저 안에서만 넣어 확인했어요. 배포 데이터에는 넣지 않았어요
- **최저가 발견 막대** (`mrange`): 비교 가능한 가격의 범위 중 최저가 위치(점)와 중간값(세로선)
  - 중간값보다 70% 넘게 낮은 것은 단위가 다른(1샷당·1개당) 경우가 많아서 빼요

## 5. 화면 구조
| 탭 | 화면 | 들어 있는 것 |
|---|---|---|
| 홈 | `#home` | "피부 시술, 이제 알고 비교해요." · 검색("어떤 피부 고민이 있으세요?") · 입구 2개 · 인기 시술 · 최저가 발견 · 가격 변동 |

| 장바구니 | `#cart` | 상품 행 · 예상 총액 · 고급 설정(접힘) · 병원별 비교(한 곳/섞기/패키지/브랜드·지역) |
| 관심 | `#saved` | 가격 알림 · 관심 시술·지점 · 최근 본 것 · 저장한 검색 조건 |

  - "리쥬란 2cc" → 가격 검색, "이마 주름이 신경 쓰여요" → 고민 가이드

### 같은 역할은 같은 모양 (2026-10-19 위계 점검 묶음 5 · 6.0 규칙 3·4)
- **배지 순서**(29): 어느 가격 줄이든 ① 가격 종류·조건(체험가·한정가·고시가, 첫 방문·평일·시간 한정 …, 버터) → ② 경고(기간 끝남·방문일엔 안 됨 = 코랄, 시간 확인 필요·기간 확인 필요 = 버터, 초저가·조건 확인·지난 자료·급변·확인 중 = 회색 + 아이콘 — 자리는 같고 색만 역할대로) → ③ 정보(~10/31까지·VAT·추가 옵션·고시표·제품·장비, 회색). `kindBadge(r, { warn, info })`가 화면 자기 배지도 같은 자리에 넣어요. 배지 글자는 그대로예요
- **접기 모양**(30): 요약 줄 하나 — 글자(앞 아이콘은 있어도 됨) + 줄 오른쪽 끝의 같은 꺾쇠(CSS 한 개, 펼치면 뒤집힘). 크기만 두 단계: 덩어리 하나인 접기는 카드 한 장에 15/600(비교 '가격 종류별…'·'뭐예요? · 규격 확인', 검색 '비슷한 종류', 고급 비교 설정, 지점 전체 목록 — 줄 접기 상세 필터·더 좁히기·내 설정도 15), 덩어리 안 접기는 13/600 회색(`fold.small`, `minifold`, 검색 팁, 제품 안내). 카드 안에 카드를 넣지 않아요: 덩어리 접기 안의 카드는 테두리를 빼고 가는 선으로 나눠요(`.cmpfold`). 덩어리 접기 위 간격은 덩어리 사이 간격(24) 그대로
- **가격 근거 ⓘ**(47): 모든 가격 줄(비교·지점 가격표·검색·전체 가격표)의 오른쪽 ⓘ 칸 하나(`infoBtn`, 보이는 칸 36px, 누르는 곳 44px — 오른쪽 카드 여백으로만 넓혀 담기와의 4px는 그대로, 화면 읽기 이름 '… 가격 근거 보기'). 줄에 '가격 근거'·'출처' 글자 링크를 두지 않아요 — 근거 창 '원본' 줄에 병원 원본 링크가 있어요. 검색 줄의 지점명 링크는 남아요
- **버튼 격자**(35): 한 덩어리의 동작 버튼은 같은 폭 2칸 격자(`.bbtns` — 지점 머리 6개, 견적 펼침 끝 4개, 위 16px). 앱 밖으로 나가는 버튼(길찾기·병원 홈페이지)은 글자 뒤 ↗(`outLink`, 새 창). 320px에서는 앞 아이콘을 숨겨 글자가 한 줄에 들어가요
- **가까운 것끼리**: 검색은 필터·결과 두 덩어리(사이 24, 안 8 — '이렇게 찾았어요'는 필터 카드 맨 위, 결과 수·안내 문장은 결과 카드 머리, 32). 지역·이름순 검색 결과는 지점마다 머리 한 번(`.sgh` — 위 24, 첫 줄까지 8로 자기 줄 쪽에 붙임), 다른 정렬은 줄마다 지점 이름(33). 이름이 여러 줄이어도 가격은 첫 줄 기준선(33). 홈 '전체 비교'는 인기 카드 바로 아래 8px, 다음 덩어리는 24px(50)
- **긴 이름**(39): 담기 글자는 `Spec.shortLabel` — 20자가 넘으면 괄호 안(패키지 구성·제품 목록)을 빼요('담기 · 리쥬베룩 패키지'). 맨 앞 괄호('(여)')와 양만 적은 괄호('(100U)'·'(1병)')는 남겨요. 이름만 보고 정해요(home.json은 시술군의 규격을 일부만 가져서, 다른 규격을 보면 홈 카드 글자가 전체 자료가 온 뒤 바뀜 — O2). 그래서 한 시술군에서 짧은 이름이 같아지는 규격이 있어요('… 200U (표기 1)'·'(표기 2)'). 전체 이름은 바로 위 제목과 화면 읽기 이름에 그대로. 패키지 경로는 두 단계 그대로

## 4. 그래프
- **그래프 글자**: 그래프는 상자의 실제 폭으로 그려요(`fitChart` — 1단위 = 1px). 고정 viewBox 340으로 그리면 13px 글자가 390px 화면에서 12.1px, 320px에서 9.4px로 줄어들었어요(위계 묶음 6 검토). 처음엔 340으로 그리고, 화면에 붙은 뒤 첫 그림 전에(접기를 열 때·화면을 돌릴 때도) 다시 그려요. 높이가 바뀌어도 되돌아 보지 않게 높이 0인 자(`.lcw`)의 폭만 지켜봐요. 축 숫자·끝 라벨 자리는 글자 폭으로 잡고, 날짜는 46px 넘게 떨어진 것만 적어요
- **병원별 가격 분포** (`distChart`)
  - 지점 하나 = 점 하나. 겹치면 위로 쌓아요
  - 채운 점 = 조건 없는 가격, 고리 = 조건부, 진한 점 = 지금 보여주는 최저가, 점선 = 중간값
  - 터치·마우스로 툴팁(지점·가격·조건부 여부)을 봐요
  - 키보드: 그래프 상자가 슬라이더예요. ←→로 지점을 옮기고 Enter로 그 지점을 열어요
  - 3곳 미만이면 그리지 않아요
- **가격 이력** (`lineChart`)
  - 축 하나, 2px 선. 단조 3차 보간이라 관측값보다 위아래로 튀지 않아요
  - 기록이 빠진 주는 선을 끊어요. 끝 라벨, 범례, 십자선 툴팁, ←→ 키, '표로 보기'
  - 선은 그려지는 애니메이션이 있어요. 움직임 줄이기(시스템 설정·'움직임 꺼짐')에서는 애니메이션 없이 바로 보여요(전에는 `animation: none`이라 선이 숨은 채였어요)
  - 지금 실제 기록은 1주(2026-10-13)라 선 없이 "첫 기록"으로 보여줘요
  - 선 모양은 시험용 가짜 데이터(6주, 1주 빠짐)를 브라우저 안에서만 넣어 확인했어요. 배포 데이터에는 넣지 않았어요
- **오늘의 발견 막대** (`mrange`, 홈 '죠미의 오늘의 발견'): 비교 가능한 가격의 범위 중 최저가 위치(점)와 중간값(세로선)
  - 중간값보다 70% 넘게 낮은 것은 단위가 다른(1샷당·1개당) 경우가 많아서 빼요

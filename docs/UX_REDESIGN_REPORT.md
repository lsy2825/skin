## 2. 지킨 원칙
- **객관 표시(지시 ②)**: 새 카드(방문 계획·가격 종류·검색 결과 종류)에 병원 이름을 앞세우지 않아요. 최저가 강조·순위·할인 강조 플래그는 계속 꺼져 있어요. `objective.js` 32/32, `pricing40` C3·C11.
- **사실만**: 제품·장비는 병원이 적은 이름만 써요. 판정은 "앱이 확인한 것 아님"이라고 적어요. 수집 상태는 GitHub이 준 값만 보여줘요.
- **접근성**
  - 새 칩은 `role=radio`/`aria-checked`를 써요.
  - 새 그래프에는 글자 설명이 있어요(`aria-label`에 지점 수·범위·중간값).
  - 터치 영역 24px 이상(`touch_targets`)
  - axe 위반 0건(`a11y`)
- **좁은 화면**: 320·390px에서 가로 넘침 0건이에요(`ux_qa`, `compare_cards`).
  - 쉬운 보기 단계가 처음에 화면을 넓혀 실패했어요(X12 909px, X24 597px).
  - 단계 줄에 `min-width:0` 그리드를 줘서 고쳤어요.

## 3. 고치면서 찾은 것
| 문제 | 고친 것 |
|---|---|
| 쉬운 보기/자세히 전환 버튼이 좁은 칸에서 글자 단위로 줄바꿈 | 고정 폭 148px |
| 쉬운 보기 단계가 320px에서 가로 넘침 | 그리드 최소 폭 0 |
| 방문 계획 B의 "가장 싼 곳" 문구가 객관 표시 시험에 걸림 | "시술별로 나눠서"로 바꾸고, 설명은 "시술마다 가격이 가장 낮은 지점에서" |
| 자연어로 지역이 빠져 나간 검색("강남")에 결과 종류 카드가 안 보임 | 원래 입력으로 찾기 |

## 4. 하지 않은 것

- 지도 바텀시트 개편: 지점별 가격 핀·목록 연동은 이미 있어요. 4.0에서는 바꾸지 않았어요.

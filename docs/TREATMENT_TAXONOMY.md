## 1. 층
지시서는 Category → Family → Product/Device → Variant → Spec → Clinic Offer → Pricing Condition이에요. 지금 데이터에서 각 층은 이렇게 돼요.

| 층 | 무엇 | 어디서 | 예 |
|---|---|---|---|
| Category(분야) | 톡신·윤곽·필러·리프팅·부스터·피부·제모·바디·패키지·기타 | `taxonomy.py CATS` | 제모·바디 |
| Family(제품군) | 같은 시술 이름(부위별로 나눈 것 포함) | `taxonomy.py FAMILIES` 120여 개 + 이름 그대로 묶음 | 겨드랑이 제모, 사각턱 보톡스, 리쥬란 |
| Product/Device(제품·장비) | 병원이 상품명에 적은 제품·장비 이름 | `classify.js products()`(장비 9종 정규화 + `spec.js PRODUCTS` 42개) | 아포지 플러스, 젠틀맥스 프로 플러스, 제오민, 리쥬란 |
| Variant(옵션) = **비교 묶음** | 같은 제품군·같은 속성·같은 용량·같은 횟수 | 직접 만든 36개(X01~X36) + 자동 2,581개(T…) | 리쥬란 힐러 2cc, 여성 겨드랑이 제모 아포지 플러스 5회 |
| Spec(규격) | 용량·샷·유닛·부위·횟수·원산지 | 비교 묶음 속성 + `spec.js parse()`(상품명에서 읽기) | 2cc · 1회 · 국산 |

### 자동 비교 묶음의 서명(signature)
`제품군 | 이름 | 속성 | 남은 낱말 | 세부(괄호·'-' 뒤) | 용량 | 횟수`

서명이 같고 3개 지점 이상이 팔면 비교 묶음이 돼요. 4.0에서 서명에 넣은 것은 다음과 같아요(`PRODUCT_AUDIT.md` F-04).
- 제모 장비 8종
- 화면에 보이는 이름에서 읽은 제모 부위
- 괄호 속 부위·성분(착색토닝, 수액)
- 개당/얼굴전체/부분(아그네스, 포텐자)
- CO2/어븀글라스(프락셀)
- LDM 분(分)
- 포텐자 펌핑 모드·팁 별도
- 외국산 = 수입

### 규격 이름(라벨)에 들어가면 안 되는 것 (2026-10-14)
사고: 피코토닝 규격 칩에 '20만원3921만재생', '미백톤업색소토닝'이 보였어요. 원인은 두 가지였어요.
- 닥터에버스 수집기가 상품명 앞에 그 상품이 있는 칸 제목을 붙였는데, 칸 제목이 가격대('20만원 39.21만')·꼬리표 목록
  ('미백 | 톤업 | 색소 | 토닝')·행사 이름('26년 10월 2차) 한글날 맞이 …')인 경우가 많았어요.
- 제품군·용량을 뺀 '남은 낱말'을 띄어쓰기 없이 붙여서 보여줬어요.

고친 곳과 막는 장치는 이래요.
- `build2/clean.py` `title_words`: 칸·묶음 제목은 제품 이름일 때만 앞에 붙여요. 가격·날짜·홍보 말은 떼고, 남는 게 시술
  이름이 아니면 붙이지 않아요. 수집기(`scrape/drevers.py`)는 상품명을 사이트 그대로 저장해요.
- `build2/taxonomy.py` `_spaced`: 남은 낱말·세부·제모 부위는 병원이 쓴 띄어쓰기대로 보여줘요. 서명은 붙인 그대로라 묶음
  ID는 바뀌지 않아요.
- `build2/clean.py`: 유앤아이는 제모 쪽 화면에 필링·스킨케어·부스터도 올려요. 이런 줄은 이제 자기 이름대로 분류해요
  ('FCR 필링 … 제모' 같은 규격이 사라짐). 부위 이름만 있는 줄('종아리+무릎')은 그대로 제모예요.
- **빌드 가드** `build2/labels.py`: 아래 규칙에 걸리는 규격은 비교 묶음을 만들지 않아요. 가격은 앱에 그대로 남고 묶이지만
  않아요. 걸린 이름은 `data2/variants.json`의 `stats.label_rejected`에 남아요.
  - 가격: '20만원', '39.21만', '99,000원'. 단 에너지 '8만 J'와 동전 크기 '500원'은 가격이 아니에요.
  - 날짜: '10월 1일', '26년 10월', '까지'
  - 홍보 말: 이벤트·특가·할인·혜택·맞이·기념·추천·안내·카카오톡 …
  - 기호: `| ｜ ※ ♥ ★ ☆`
  - 괄호: 빈 괄호 '()', 괄호 안쪽 끝 공백 '(1회 )', 짝이 안 맞는 괄호 (') 비타민관리'). 원인인 `taxonomy._tidy`가 체험가 같은 말을 뗀 뒤
    남은 빈 괄호·짝 없는 괄호를 정리하고, '男)'·'女)'는 '남성'·'여성'으로 바꿔요.
  - 붙은 글자: 8글자 이상 붙은 말이 그 묶음 상품명 어디에도 그렇게 쓰여 있지 않음. 병원이 원래 붙여 쓴 말은 괜찮아요.
- 시험: `tests/labels_test.py`(규칙·원인·가드·배포 데이터, 회귀에 포함)와 `tests/labels.test.js`(배포되는 `app/data.json`).

## 2. 선택 흐름 (쉬운 보기 · 자세히)
비교 화면에서 제품군을 고르면 **쉬운 보기**(기본)가 단계별로 보여줘요.
1. **종류**: 비교 묶음 이름에서 용량·횟수를 뺀 나머지(원산지·제품·장비·부위 낱말)
2. **용량·부위**: 그 종류 안의 용량·샷·유닛·부위
3. **횟수**: 1회 / N회 묶음

예시는 이래요.
- 리쥬란 → 종류(힐러·HB 플러스·아이 힐러…) → 용량(1cc·2cc…) → 횟수(1회·3회 묶음)
- 보톡스 → 부위(사각턱 보톡스 등 제품군 선택) → 종류(국산·독일산·프리미엄) → 유닛(50U·100U) → 횟수

동작 방식은 다음과 같아요.
- 단계 칩을 누르면 앞 단계의 선택을 지키면서 가장 가까운 비교 묶음으로 옮겨요.
- 같은 조건이면 파는 지점이 많은 쪽을 골라요.
- 선택지가 하나뿐인 단계는 숨겨요.

**자세히**는 예전처럼 모든 옵션을 종류별 줄로 보여줘요. 고른 보기 방식은 이 기기에 저장돼요(`pc:cmpMode`).

## 4. 제품·장비가 섞인 묶음
- 한 묶음에 제품·장비가 둘 이상이면 가격 요약 위에 안내를 띄워요. 제품이 적힌 곳과 안 적힌 곳이 섞여 있어도 마찬가지예요.
- 지점 목록에는 '제품·장비' 칩이 붙어요: 전체 / 제품별 / 표기 없음, 숫자는 파는 지점 수.
- 칩을 누르면 그 제품을 적은 줄만으로 지점별 가격을 다시 골라요(`prodRank`). 줄마다 제품 표시가 붙어요.
- 지금 섞인 묶음은 51개예요(대기열 C).
  - 직접 만든 묶음: X03 스킨보톡스(보툴렉스·리즈톡스·나보타가 몇 줄), X10 수입 필러(벨로테로·레스틸렌·쥬비덤 — 묶음 이름부터 세 제품을 함께 비교), X28·X30·X35
  - 나머지는 자동 묶음

## 5. 바뀐 비교 묶음 ID의 처리
분류 규칙을 고치면 자동 묶음 ID가 바뀌어요. 이렇게 처리해요(`PRODUCT_AUDIT.md` F-06·F-07).
- **ID 연결표 `meta.keymap`**: 옛 ID를 새 ID에 이어요. 이번엔 396개 중 328개를 이었고, 이어지지 않는 68개는 옛 이름으로 보여줘요.
- **다시 묶인 ID 목록 `meta.recl`**: 이번에 330개예요(같은 지점의 같은 이름 줄을 합쳐 대조한 뒤 값). 이 묶음들은 다음처럼 다뤄요.
  - 가격 변동·검토 대기에서 빼요. 2026-10-16부터는 **줄이 옮겨진 지점만** 빼요(`meta.reclBranches`, `build2/appdata.py`
    `recl_pairs`). 지점의 최저가는 그 지점 줄로만 정해져서, 다른 지점의 진짜 변동은 남겨요(쁨 울산점 줄 때문에 TA42833F 쥬베룩
    스킨 부스터 2cc의 다른 쁨 7곳 149,000 → 250,000이 빠졌던 일). 이 칸이 없는 예전 `data.json`이 적은 ID는 모든 지점에서 빼요.
    같은 수집을 다시 빌드할 때는 지점마다 일반가 최저가를 이전 판(그 판의 규칙, 빌드 날짜에 끝난 이벤트 줄은 빼고)과도 견줘서, 다르면
    그 지점도 규칙 탓으로 봐요(`same_collection_moved`) — 규칙이 줄 이름을 바꿔 이름으로는 이전 줄을 못 찾는 경우. 다음 수집에서
    이름이 바뀐 줄은 진짜 가격 변화와 구별할 수 없어 그대로 남아요(예전 ID 단위 거르기도 다른 지점이 함께 옮겨졌을 때만 우연히 가렸어요).
  - 가격 이력은 이날부터 다시 그려요(ID 단위 그대로 — 여러 지점의 중간값이라).
  - 알림은 알리지 않고 기준만 다시 잡아요(ID 단위 그대로).
- 이 기기의 장바구니·관심·알림·저장한 비교는 앱을 열 때 새 ID로 옮겨요. 지우는 항목은 없어요.

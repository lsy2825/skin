## 4. 돌리지 못한 것
- 실제 iPhone·Android에서의 설치·알림·오프라인(실기기 없음)
- 배포 주소에서의 동작(접속 막힘). GitHub Actions 배포 성공만 확인했어요.
- 실제 GitHub API를 앱 화면에서 누른 결과. 테스트는 응답을 흉내 냈어요. 실제 응답 형식은 curl로 확인했어요.
- 경쟁 앱 화면(설치·로그인 안 함)

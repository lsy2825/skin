# 고급 검색 명세 (Advanced Search)

기준일: 2026-10-14. 코드: `app/domain/search.js`의 `compile()`·`qtys()`·`hasOps()`. 테스트: `tests/search.test.js`(연산자 9개), `tests/e2e/pricenow.js` S4~S8.

## 1. 문법
검색어는 띄어쓰기로 나눈 낱말들이에요. 모든 낱말은 같은 정규화를 거쳐요.
- 정규화: 소문자, 단위 통일(U·유닛·단위·unit → u, ml·cc → cc, 만줄 → kj, `1,300` → 1300), 공백·문장부호 제거, 별칭 → 대표 이름(보톡스 → 톡신, rejuran → 리쥬란, 독일산톡신 → 제오민 …)

| 문법 | 예 | 뜻 |
|---|---|---|
| 낱말 여러 개 (AND) | `보톡스 50U` | 모두 들어간 가격만 |
| `-낱말` (제외) | `사각턱 50U -제오민` | 이 낱말(별칭 포함)이 있으면 뺌. `-보톡스`는 '톡신'도 뺌 |
| `a|b` (OR) | `제오민|코어톡스` | 둘 중 하나. 한 낱말 안에서 띄우지 않고 씀 |
| 숫자+단위 (정확 일치) | `300샷`, `2cc`, `50U`, `1회`, `1개` | 상품명에서 숫자를 **통째로** 읽어 같은 값만. `1300샷`은 1300이라 `300샷`에 안 걸림. `12개월`은 개수가 아님 |
| 숫자+단위`?` (적혀 있으면) | `1회?`, `50U?` | 그 단위가 상품명에 적혀 있으면 그 값만. 안 적혀 있으면 남기되 **'횟수 표기 없음'** 표시(1회로 단정하지 않음) |
| 섞어 쓰기 | `리쥬란2cc`, `-1300샷`, `300샷|1300샷 1회` | 낱말 부분과 숫자+단위 부분을 나눠서 둘 다 맞아야 함 |

인식하는 단위: 샷, 회, 개(개월 제외), 부위, 줄, 분, U, cc, KJ, mm, cm.

### `1회?`와 `1회`
- 지시서: "명시적으로 1회인 항목을 검색, 횟수가 없는 항목을 1회로 추정하지 마세요."
- 참고 사이트: "`1회?` 횟수가 적혀 있으면 1회만."
- 윤실장은 둘 다 지켜요.
  - `1회`는 상품명에 1회가 적힌 것만 찾아요(명시적 1회).
  - `1회?`는 횟수가 적힌 상품은 1회만 남기고, 적히지 않은 상품은 남기되 '횟수 표기 없음'으로 따로 표시해요.
  - 어느 쪽도 횟수가 없는 상품을 '1회'라고 보여주지 않아요.

## 2. 구조
1. `compile(q, index)` — 검색어를 한 번만 해석해서 `{test, unstated, parts, warn, fixes, tokens, raw, empty, ops}`를 돌려줘요.
   - `test(정규화한 상품명)` → 참/거짓. AND 묶음마다 OR 후보 중 하나가 맞고, 제외 묶음은 하나도 안 맞고, `?` 조건을 지켜야 참이에요.
   - 낱말 부분은 정규화된 이름 안에 들어 있는지 봐요. 숫자+단위 부분은 `qtys()`가 이름에서 읽은 `{n, u}` 목록과 비교해요(문자열 포함 검사로 규격을 판정하지 않아요).
   - `qtys()`는 결과를 기억해 둬서(최대 6만 개) 같은 이름을 다시 읽지 않아요.
2. 오타 교정: 숫자가 없는 단독 낱말이 어떤 상품명에도 없으면 자모 거리 1~2의 단어로 바꾸고 알려요. 제외 낱말·OR 낱말은 바꾸지 않아요(엉뚱한 걸 빼지 않게).
3. 잘못된 입력: `-` 혼자, `|` 한쪽이 빔, `?`를 숫자+단위가 아닌 낱말에 붙임, 찾을 글자가 없는 낱말은 **무시하고 이유를 알려요**. 예외를 던지지 않아요(빈 검색어·기호만·이모지 포함 18가지 입력으로 테스트).
4. 자연어 해석(`강남 슈링크 10만원 이하`)은 연산자가 없을 때만 해요. `hasOps()`가 `-낱말`, `|`, `숫자+단위?`를 찾으면 건너뛰어요. "어디가 싸?" 같은 보통 물음표는 연산자로 보지 않아요.

## 3. 쓰는 곳
- 검색 결과(`#search/…`), 전체 가격표(`#table?q=…`), 시술 종류 찾기(`famFind`), '같은 조건 가격 비교 바로가기'(비교 키 이름).
- 결과 위 **'이렇게 찾았어요'** 카드: 포함 / 정확히 / 빼기 / 둘 중 하나 / 적혀 있으면 — 그리고 무시한 것.
- 결과 줄: `?` 조건에서 단위가 안 적힌 상품에 '횟수 표기 없음' 같은 표시.
- 결과가 0개일 때 '‘낱말’ 빼고 찾기'도 같은 문법으로 다시 계산해요.

## 4. 처음 쓰는 사람용 (문법을 몰라도 같은 조건으로)
| 조건 | 문법 | 필터로 |
|---|---|---|
| 제품 | `제오민` | 가격표 '제품·장비' 칩(상품명에 적힌 제품·장비) |
| 용량·샷 수 | `300샷` | '용량·샷 수' 칩 |
| 부위·원산지·성별 | `사각턱`, `국산` | '세부 구분' 칩 |
| 횟수 | `1회?` | '가격 조건' → 회차·패키지 |
| 장비 | `울쎄라` | '제품·장비' 칩 |
| 지역·브랜드 | — | 필터 줄의 지역·브랜드 |
| 가격 조건 | — | '가격 조건' 창(조건부·종류·첫 방문·묶음·회차·부가세·확인 필요) |

검색창 아래 **'검색 팁'**(접힘): 죠미가 한 줄로 설명하고 예시 4개를 눌러서 바로 찾을 수 있어요 — "50U만 찾고 싶다면?", "특정 단어를 빼려면?", "두 제품 중 하나를 찾으려면?", "횟수가 적힌 것 중 1회만?".

## 5. 성능
- 단위 테스트: 6만 개 이름을 1초 안에(실측은 수십 ms, `tests/search.test.js` 'speed').
- 가격표는 62,404줄 × (결과 + 필터별 개수 8가지)를 매번 계산해요. 연산자 검사 비용은 이름 하나당 정규식 1번(기억해 둠)이에요.

## 6. 한계
- 상품명에 쓰인 것만 찾아요. 병원이 '1회'를 이름에 안 쓰면 횟수를 몰라요.
- 따옴표로 묶은 구절 검색, 괄호 묶음, `OR`를 낱말 사이에 쓰는 문법은 없어요.
- 별칭 사전에 없는 영문·약어는 그대로 찾아요(예: 새 장비 이름).

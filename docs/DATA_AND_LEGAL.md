## 2. 심평원 비급여 진료비 API 적합성 (DATA01)

검토 패키지가 확인한 사실: API가 존재하고 설명에는 '병원급 이상'이 적혀 있음([S07] data.go.kr 15001700). **미용 시술(보톡스·레이저 등)과 의원급 체인이 필요한 규격으로 들어 있는지는 확인 불가**예요. 이번 환경에는 API 키가 없어서 실제 응답을 받지 못했어요.

키를 받으면 할 최소 검증(쓸 수 없으면 대량 연동을 만들지 않음):

1. 항목 코드 목록을 받아 미용 관련 키워드(보툴리눔, 필러, 레이저, 리프팅 등)가 있는 코드만 추림 → 몇 개인지 기록.
2. 그 코드로 기관별 가격을 조회 → 응답에 **의원급**이 있는지, 우리 4개 체인 지점이 있는지(이름·주소로 대조) 확인.
3. 규격 대조: 응답의 단위(1회·cc·U·샷 등)가 우리 비교 묶음(`app/data.json` keys)에 1:1로 맞는지 20건 표본으로 손 검사.
4. 갱신 주기·기준일·이용 조건(공공누리 유형, 출처 표시)을 기록.
5. 판단: 표본 20건 중 규격이 맞는 비율과 의원급 포함 여부로 '고시 정가 층'으로 넣을지 결정. 이벤트가와 섞지 않음(리엔장 고시표처럼 별도 표시).

질의 예(키 자리는 비움): `GET https://apis.data.go.kr/B551182/nonPaymentDamtInfoService/<operation>?serviceKey=<KEY>&...` — **operation 이름·파라미터는 공식 명세에서 확인 필요(확인 불가).**

## 4. 법률 검토 질문 (LEG01~04) — 화면·흐름과 함께 전달할 질문

### LEG01 의료광고·환자 유인
- 윤실장은 병원이 게시한 가격을 모아 **같은 규격끼리 나란히** 보여줘요. 병원에게서 받는 돈은 지금 없어요. 이 구조에서 앱 화면이 '의료광고'에 해당할 수 있나요? 해당한다면 광고 주체는 누구로 보나요?
- 가격 순 정렬(사용자가 고를 때만), 중간값·범위 표시, '조건부 가격' 분리 표시가 비교·재가공 광고 규정에 걸리나요? 할인율은 기본 화면에 표시하지 않아요(`discountEmphasis=false`).
- 고민 화면의 '가격 비교' 버튼(사용자가 누를 때만)이 환자 소개·알선·유인 우려가 있나요?
- 향후 병원 대상 서비스(B2B)나 정액 광고를 한다면 어떤 형태가 문제가 되나요? (특정 판례를 이 앱에 그대로 적용하지 않음)

### LEG02 수집·재게시
- 공개 가격 페이지를 주 1회 수집해 재게시하는 것의 계약·권리(이용약관, 데이터베이스 제작자 권리, 부정경쟁 관련 조항) 쟁점. 의무 공개 가격이라는 사실이 재게시를 허용한다고 볼 수 있나요?
- 병원 로고·사진은 쓰지 않아요(브랜드 이름·색 점만). 지도는 OpenStreetMap(출처 표시), 글꼴 Pretendard(OFL), 아이콘 Lucide(ISC), 지도 라이브러리 Leaflet(BSD-2). 문제없나요?
- 삭제·정정 요청 처리 기한과 절차의 적정 수준.

### LEG03 크레딧·환불
- 자기 서비스에만 쓰는 선불 크레딧의 법적 성격(선불전자지급수단 해당 여부), 유효기간 없음 정책.
- 청약철회: 전자상거래법 제17조의 디지털콘텐츠 관련 조건(제공 개시·가분성)이 '크레딧 묶음'과 '이미 받은 보고서'에 각각 어떻게 적용되나요? (원장은 쓰지 않은 구매 크레딧만 비례 회수하도록 구현됨)
- 거래 기록 보존(법정) 기간과, 탈퇴 후 개인정보 삭제의 구분 — 구현: 탈퇴 시 개인 정보는 즉시 삭제, 거래 원장은 이름·연락처 없이 계정 번호만 남기고 `closed_accounts.purge_after`(비워 둠)까지 보관. 이 기간을 정해 주세요.

### LEG04 개인정보·민감정보
- 아래 데이터 흐름(§5)에서 민감정보·국외 이전·처리 위탁이 생기는 지점과 필요한 고지·동의.
- 사진 읽기(꺼짐)를 켤 경우: 얼굴이 찍힌 사진의 처리 근거, 외부 AI 제공자로 보내기 전 선택·경고·삭제 흐름의 충분성, 제공자의 보존·학습 설정 확인 범위.

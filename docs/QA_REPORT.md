## 3. 성능 (실험실)
- 첫 방문(느린 4G = Lighthouse 휴대폰 기본값): LCP 0.86초, CLS 0, 가격이 보이기까지 8.8초(개선 전 12.0초). 자세히: `DESIGN_SYSTEM.md` '첫 화면 속도'
- **누르기 반응(INP 유사)** — 7번 누르기(탐색 탭·정렬 칩·카드 보기·목록 보기·가격 근거·장바구니 탭·홈 탭) 중 가장 느린 것, 5회 중간값:

| | 첫 방문 | 재방문 | 가장 느렸던 누르기 |
|---|---|---|---|
| 느린 기기 가정(CPU 4배 느림) | 0.18초 | 0.20초 | 카드 보기 / 홈 탭 |
| 빠른 기기 | 0.06초 | 0.05초 | 카드 보기 / 정렬 칩 |

  - 개선 전(같은 날, 정렬·보기를 바꿀 때 화면 전체를 다시 그리던 때): 느린 기기 가정 0.30~0.49초, 빠른 기기 0.07~0.08초
  - 기준: Google은 0.2초 이하를 '좋음'으로 봐요. 느린 기기 가정에서 경계에 있어요.

- INP는 원래 실제 사용자에게서 모으는 지표예요. 여기 숫자는 같은 방식(Event Timing)으로 실험실에서 잰 참고값이에요.

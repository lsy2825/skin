## 1. 비교할 수 있는가 (comparability)
| 단계 | 규칙 | 4.0에서 바뀐 것 |
|---|---|---|
| 같은 묶음 | 같은 제품군·속성·용량·횟수(`TREATMENT_TAXONOMY.md`) | 횟수·원산지·장비·부위 규칙 결함 4개 수정(`PRODUCT_AUDIT.md` F-01~F-05) |
| 지점별 대표 가격 | 지점마다 살아 있는(만료·검토 대기·방문일 조건 불가 제외) 가장 싼 가격 하나. '특가 포함'을 끄면 체험가·한정가·조건부 제외 | 그대로 |
| 비교 판정 | 가격 줄마다 A~J·R(가격 근거 창 맨 위) | **새로 만듦** |
| 제품·장비 섞임 | 안내 + 제품별 거르기(`prodRank`) | **새로 만듦** |

## 2. 가격 종류 (price class)
| 종류 | 근거 | 화면 |
|---|---|---|
| 일반가 | 가격 종류 '일반' + 조건 태그 없음 | 가격 종류별 범위, 가격 근거 '가격 종류' |
| 이벤트가 | 체험가·한정가(병원 표기) | 〃 |
| 조건부 | 첫 방문·평일 낮·요일·시간 태그 | 〃 |
| 고시가 | 비급여 진료비 고시표(리엔장) | 〃 |
| 구독권 | 구독권·이용권 | 가격 근거만(비교 묶음에 안 들어감) |

**가격 종류별 범위 카드**(비교 화면, 분포 그래프 아래)
- 종류마다 지점별 그 종류 최저가를 모아서, 범위 막대와 중간값 눈금을 **한 눈금 위에** 그려요.
- 축은 하나예요(`dataviz` 원칙: 이중 축 없음).
- 각 줄에 지점 수·범위·중간값을 글자로도 적어요(색만으로 구분하지 않음, 화면 읽기 프로그램용 설명 포함).
- 병원 이름은 없어요(지시 ②).
- "100원~10만 원" 같은 넓은 범위가 데이터 오류가 아니라 이벤트가와 일반가의 차이라는 걸 보여줘요(`PRODUCT_AUDIT.md` F-12).

## 3. 부가세
- 브랜드별 '부가세 별도' 근거(공식 페이지 문구·확인일)가 `meta.about.vat`에 있어요.
- 상품명에 '부가세 포함'이 적힌 줄은 포함으로 봐요.
- **확인 못 한 줄은 더하지도 빼지도 않고 "부가세 포함 여부를 사이트에서 찾지 못했어요"**라고 보여줘요(VAT UNKNOWN).
- 2026-10-14 데이터에는 확인 못 한 줄이 0줄이에요. 네 브랜드 모두 근거가 있어요.

## 4. 가격 근거 창 순서 (고정)
1. 상품명·가격·지점·가격 종류 배지
2. **비교 판정**(A~J·R + 이유 + 'A~J 뜻')
3. 가격 적용 조건(첫 방문·체험가·부가세·기간·그 밖의 조건)
4. 시술 규격 확인(접힘)
5. (초저가면) 경고
6. 사실 목록
   1. 가격과 부가세
   2. **가격 종류**
   3. 조건
   4. 회차
   5. 유효기간
   6. 비교 기준
   7. 정가(병원 표기)
   8. 확인일
   9. 원본
   10. 원본 대조
   11. 검토
   12. 정품 표기
   13. 시술 의료진
   14. 부작용·주의사항
7. 체크리스트·비교함, 이 가격 다시 확인하기, 원본과 달라요

`pricing40.js` C4가 6번 사실 목록의 1~9번 순서를 확인해요.

## 6. 한계
- 가격 종류는 병원이 적은 표기로만 정해요. 표기 없이 행사 중인 가격은 '일반가'로 보일 수 있어요. 아주 싼 일반가는 '초저가'·판정 R로 따로 알려요.
- 회당 환산은 비교 판정의 기준(중간값)에만 쓰고, 다른 횟수끼리 섞어 비교하지 않아요.

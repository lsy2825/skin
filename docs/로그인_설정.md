# 로그인(구글·카카오) 켜는 방법

지금은 **꺼져 있어요**. `app/config.js`가 비어 있으면 로그인 버튼이 안 보이고, 마이 탭의 정보는 각자 휴대폰에만 저장돼요.
아래 순서대로 하면 켜져요. 계정 만들기·키 발급은 직접 하셔야 해요(대신 가입해 드릴 수 없어요). 전부 무료 플랜으로 돼요.

> 켜기 전에: 나이·성별·받은 시술 기록은 건강 관련 정보라, 모르는 사람에게 받는다면 개인정보 수집 동의와 처리방침이 필요해요
> (개인정보보호법상 민감정보로 볼 수 있음 — 법률 판단이 아니라 주의사항이에요).

## 1. Supabase 프로젝트 만들기 (약 5분)
1. https://supabase.com 가입 → **New project** → 이름 `skin`, 지역 **Northeast Asia (Seoul)**, DB 비밀번호 저장.
2. 왼쪽 **SQL Editor** → `supabase/schema.sql` 내용 전체 붙여 넣기 → **Run**. (회원 표 2개 + "자기 것만 보기" 보안 규칙 + 탈퇴 기능)
3. **Project Settings → API**에서 두 값을 복사:
   - Project URL (예: `https://abcd1234.supabase.co`)
   - `anon` `public` key (공개돼도 되는 키예요. `service_role` 키는 절대 넣지 마세요)
4. **Authentication → URL Configuration**
   - Site URL: `https://lsy2825.github.io/skin/`
   - Redirect URLs에 `https://lsy2825.github.io/skin/` 추가

## 2. 구글 로그인 (약 10분)
1. https://console.cloud.google.com → 프로젝트 만들기 → **API 및 서비스 → OAuth 동의 화면**(외부, 앱 이름·이메일 입력).
2. **사용자 인증 정보 → OAuth 클라이언트 ID → 웹 애플리케이션**
   - 승인된 리디렉션 URI: `https://<내 프로젝트>.supabase.co/auth/v1/callback`
3. 나온 클라이언트 ID·보안 비밀 → Supabase **Authentication → Providers → Google**에 붙여 넣고 켜기.

## 3. 카카오 로그인 (약 10분)
1. https://developers.kakao.com → 내 애플리케이션 → 앱 추가.
2. **카카오 로그인** 켜기 → Redirect URI: `https://<내 프로젝트>.supabase.co/auth/v1/callback`
3. **동의항목**: 닉네임(필수), 프로필 사진(선택), 카카오계정(이메일)(선택 — 비즈 앱 전환 전엔 '선택'만 가능).
4. **앱 키 → REST API 키**, **보안 → Client Secret** 생성·활성화.
5. Supabase **Authentication → Providers → Kakao**에 REST API 키(Client ID)와 Client Secret 붙여 넣고 켜기.

## 4. 앱에 키 넣기
`app/config.js`의 두 칸을 채워서 커밋하면(또는 저에게 값을 알려 주시면) 약 2분 뒤 휴대폰 앱에 로그인 버튼이 생겨요.

```js
window.APP_CONFIG = {
  supabaseUrl: "https://abcd1234.supabase.co",
  supabaseAnonKey: "eyJ...",          // anon public key
  providers: ["kakao", "google"],     // 하나만 쓰려면 하나만
};
```

## 저장되는 것 / 보는 곳
- `profiles`: 닉네임, 성별, 나이대 · `records`: 받은 날, 시술, 브랜드·지점, 금액, 메모
- 운영자는 Supabase **Table Editor**에서 전체 회원 정보를 표로 봐요. 회원은 자기 것만 읽고 쓸 수 있어요.
- 회원 탈퇴(마이 → 계정 → 회원 탈퇴)를 하면 로그인 계정과 프로필·기록이 함께 지워져요.
- 로그인 전 휴대폰에 쌓인 기록은 로그인하면 계정으로 합쳐져요.

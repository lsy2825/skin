## 5.0 수익화 → 6.0에서 제거됨

크레딧·지갑·결제·프리미엄 도구·관리자 대시보드·단위 경제성 카드는 6.0(2026-10-15)에서 지웠어요. 서버·DB 쪽은 A3(#9), 앱 화면은 B2(#8), 운영 현황의 '크레딧 단위 경제성' 카드와 '관리자 대시보드' 카드는 A6(#23), 남은 파일(`app/domain/demowallet.js`·`economics.js`, `tools/unit_economics.js`, `tests/commerce.test.js`)은 B7(#29)에서요. `supabase/commerce_seed.sql`은 #29 뒤에 A가 지워요. 그래서 아래 표의 옛 항목은 더 이상 없어요: 시연 지갑·충전, 프리미엄 도구, 가격 이력 보고서, AI 사진 읽기, 크레딧 원장, 토스 웹 결제, Apple·Google 결제, 관리자 대시보드, 단위 경제성, 서버 모드 결제 화면.

| 기능 | 상태 | 증거 / 한계 |
|---|---|---|
| 웹 푸시·가격 지켜보기 | 6.0 A5로 다시 만드는 중(`cf/alerts`, Cloudflare Worker + D1, 로그인 없음) | 서버 쪽 푸시 조각(`server/src/push.mjs`)만 남김(A3). 앱 구독 화면은 B6(#19) |

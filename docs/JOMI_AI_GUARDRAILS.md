# 죠미 심화 질문 안전장치

> **없어진 기능(6.0, 2026-10-15).** 크레딧·AI 심화 질문을 없애며 `app/domain/jomiqa.js`(B7)와 서버 AI 호출(A3)을 지웠어요. 아래는 기록이에요.
> 지금의 무료 죠미 대화 규칙은 `app/domain/jomichat.js` 하나예요(시험: `tests/jomichat.test.js`, 점수: `node tools/jomi_chat_eval.js`).

원천: `app/domain/jomiqa.js`(앱·서버 공용), `server/src/ai/jomi.mjs`(AI 호출). 테스트: `tests/commerce.test.js` 4번, `server/test/api.test.mjs` 9번, e2e C17·C18.

## 1. 세 겹

1. **선별(screen)** — 크레딧·모델 호출 없이 정해진 안내:
   - 응급(호흡 곤란·실신·심한 부기·고열·출혈·시야 이상 등) → 병원·119 연락 안내
   - 진단('무슨 병', '제 피부 상태') → 의료진만 판단 가능
   - 용량('몇 유닛 맞아야', '적정 용량') → 의료진이 정함, 죠미는 같은 용량끼리 가격만 비교
   - 처방·약 / 임신·수유 → 의사·약사 상담
2. **근거(facts)** — 질문에 나온 시술 이름으로 비교 묶음 최대 3개를 찾고, 묶음마다 지점 수·최저·중간값·최고·기록 주 수, 데이터 날짜만 줘요. 모델은 이것만 받아요.
3. **검사(check)** — 답 속 모든 'N원'이 근거 숫자 중 하나여야 하고, 진단·처방·용량 권장·효과 보장·부작용 없음 표현이 없어야 하며, 1,200자 이하. 어기면 같은 근거로 만든 **규칙 기반 답**으로 바꾸고(추가 차감 없음) 이유를 표시해요(api 9: "보통 77,000원" → 교체).

## 2. 세션

- 1크레딧 = 질문 5개 세션. 첫 답이 나와야 차감(시술 이름을 못 찾으면 반환). 후속 4개는 무료, 6번째는 `SESSION_FULL`.
- 시연(DEMO)은 AI 없이 규칙 기반 답만(화면에 '규칙 기반 답' 표시). 서버에 AI 키가 있을 때만 AI 답을 시도해요.
- 죠미 이미지는 원본 그림만 써요(새 고양이 그림을 만들지 않아요).

## 3. 하지 않는 것

진단, 용량·샷 수 권장, 약 추천, 효과·안전 보장, 병원 추천·순위, 근거에 없는 가격·통계·기간 만들기, 사용자 글 속 지시 따르기.

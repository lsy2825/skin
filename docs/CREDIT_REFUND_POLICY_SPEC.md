# 크레딧 환불 정책 명세 (초안 — NEEDS_LEGAL_REVIEW)

이 문서의 '정책'은 **법률 검토 전 초안**이에요. 전자상거래법(청약철회), 콘텐츠·디지털 상품 관련 규정, 선불 결제 수단 관련 규정이 이 상품에 어떻게 적용되는지 확인하지 않았어요(모르겠어요). 앱 화면에도 '초안 — 법률 검토 전'으로 표시해요.

## 1. 초안 정책

| 경우 | 처리(초안) | 원장 동작 |
|---|---|---|
| 결제 후 쓰지 않은 구매 크레딧 | 7일 안 전액 환불 요청 가능 | `commerce_refund(REFUND)` 전액 → 크레딧 전부 회수, 광고 없는 기간 제거 |
| 일부 사용 후 | 남은 구매 크레딧 비례 환불 검토(자동 아님) | 관리자 확인 후 부분 환불; 자동 환불은 `CREDITS_ALREADY_SPENT`로 멈춤 |
| 보너스 크레딧 | 환불 대상 아님 | – |
| 결제사·카드사 차지백 | 결제사 결정 따름 | `kind=CHARGEBACK, provider_done=true` → 남은 몫 회수, 나머지 '회수 못 함' 기록 |
| 스토어 환불(Apple/Google) | 스토어 결정 따름 | `kind=REVOCATION, provider_done=true` |
| 기능 실패·시간 초과 | 자동으로 차감 안 함 | 예약 반환(환불이 아니라 처음부터 차감하지 않음) |
| 이미 받은 보고서 | 환불돼도 남김 | 보고서 행 유지 |

## 2. 계산 규칙 (구현됨, 테스트됨)

- 회수 크레딧 = round(묶음 크레딧 × 환불액 ÷ 결제액). 마지막 환불이면 남은 몫 전부(반올림 누적 오차 없음).
- 회수는 쓰지 않은 구매 크레딧까지만. 잔액은 음수가 되지 않아요.
- 부분 환불 6+6(12크레딧 묶음 반씩), 초과 환불 거절, 같은 환불 ID 재처리 무변화 — 원장 8번 테스트.
- `GET` 미리보기: `commerce_preview_refund`(환불 가능 금액, 회수 대상, 남은 크레딧, 자동 처리 가능 여부).

## 3. 확인이 필요한 것 (법률·회계)

- 디지털 콘텐츠의 청약철회 제한 요건(사용 시작 고지 등)을 이 상품에 적용할 수 있는지.
- 유효기간 없는 선불 크레딧의 회계 처리(부채 인식)와 미사용 잔액 처리.
- 선불전자지급수단 해당 여부(이 서비스 안에서만 쓰는 크레딧이라 해당하지 않을 수 있다는 것은 **추측**이에요 — 확인 필요).
- 미성년자 결제 취소 대응.

# 모션 디자인 시스템

기준일: 2026-10-14. 코드: `app/styles.css`(토큰·키프레임), `app/app.js applyMotion`·`smooth`. 테스트: `tests/e2e/jomi.js`(기기 동작 줄이기), `tests/e2e/demo_features.js`(움직임 끄기 → `html.calm`), `tests/e2e/a11y.js`.

## 1. 원칙
1. 모션은 **변화를 알려 줄 때만** 써요. 가격이 바뀌었을 때, 담겼을 때, 새 화면이 열렸을 때가 그래요. 꾸밈용 반복 애니메이션은 없어요.
2. 짧게 써요. 0.14~0.32초, 선 그래프 그리기만 0.8초예요.
3. **동작 줄이기**를 따라요. 기기의 '동작 줄이기' 설정 또는 마이 → 죠미 설정의 '움직임 끄기'를 켜면 모든 애니메이션·전환·부드러운 스크롤을 꺼요(`html.calm`). 정보는 그대로 다 보여요.
4. 가격을 강조하는 모션은 쓰지 않아요. 최저가에 반짝임·튀는 효과가 없어요(지시 ②).

## 2. 토큰
| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--fast` | 0.14s | 누름 피드백, 색 바뀜, 칩·버튼 |
| `--mid` | 0.24s | 화면 들어오기, 탭·스위치, 그림자 |
| `--ease` | cubic-bezier(.2, .8, .2, 1) | 기본 감속 곡선 |

## 3. 정해진 움직임 (P0 = 꼭 필요, P1 = 있으면 좋음)
| 이름 | 등급 | 언제 | 정의 |
|---|---|---|---|
| `viewin` | P0 | 화면 전환 | 0.24s, 아래 8px → 제자리 + 투명 → 보임 |
| `sheetin` | P0 | 아래에서 올라오는 창 | 0.18~0.32s |
| `tick` | P0 | 요약 가격·장바구니 합계가 바뀜 | 0.32s, 아래 6px에서 올라오며 나타남. 값이 실제로 바뀐 때만 |
| `bump` | P1 | 장바구니 배지·담기 버튼 | 0.4~0.45s, 1 → 1.35 → 1 |
| `draw` | P1 | 가격 이력 선 | 0.8s 선 그리기(관측한 날만 잇는 선) |
| `popin` | P1 | 그래프 점 | 0.5s |
| 머리말 상태 점 깜빡임 | P1 | 새 가격 받는 중 | 동작 줄이기면 멈춤 |

## 4. 4.0에서 추가한 화면
방문 계획 A~D, 가격 종류별 범위, 비교 판정, 쉬운 보기 단계, 검색 결과 종류 카드에는 **새 애니메이션을 넣지 않았어요.**
- 기존 `viewin`·칩 누름 피드백만 따라요.
- 쉬운 보기 단계 칩을 누르면 화면 전체가 다시 그려지며 `viewin`이 적용돼요.

## 5. 확인
- 움직임 끄기 → `html.calm` 켜짐, 새로고침 뒤에도 유지(`demo_features.js`); 기기 동작 줄이기(`jomi.js`)
- 접근성: axe에서 모션 관련 위반 없음(`a11y.js`)

## 6. 하지 않은 것
- 화면 사이 공유 요소 전환(View Transitions API): 지원 브라우저가 한정돼 있고, 지금 화면 구조(통째로 다시 그리기)와 맞지 않아요.
- 손가락 끌기 제스처(창 끌어내리기 등): 닫기 버튼·Esc·바깥 누르기로 충분하고, 오작동 위험이 있어요.

- 최소 결제 조건은 상품명에 적힌 경우만 알 수 있어요. 세 예시의 이름에는 없어요. 병원 페이지의 공통 안내문(예: 체험가 1인 1회)은 수집하지 않아서, 실제 조건은 모르겠어요. 앱은 "병원 원문으로 확인하세요"라고 안내해요.

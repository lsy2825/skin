# 가격 정보의 객관적 배치 원칙

기준일: 2026-10-13. 사용자 지시 "② 단순 '가격 정렬(최저가순)' 배제 및 정보의 객관적 배치"를 앱에 반영한 기록이에요.
- 지시서가 짚은 위험: 특정 병원을 최저가로 맨 위에 고정해 보여주거나 과도한 할인을 부추기면 불법 환자 유인으로 판단될 수 있어요.
- **이 문서는 법률 의견이 아니에요.** 위험을 줄이는 쪽으로 화면을 바꾼 것이고, 충분한지는 법률 검토에서 정해야 해요(`LEGAL_REVIEW_CHECKLIST.md` B·F).
- 확인: `tests/e2e/objective.js` 26/26

## 1. 원칙
1. **기본 순서는 가격과 무관하게.**
   - 지점 목록은 처음에 지역·지점 이름순으로 보여줘요. 기준 위치를 정하면 가까운순이에요.
   - '낮은 가격순'은 사용자가 고르는 여러 정렬 중 하나예요. '높은 가격순'도 같이 둬요.
2. **특정 병원을 '최저가'로 앞세우지 않기.**
   - 화면 맨 위 요약은 같은 조건 가격의 **범위와 중간값**이에요. 병원 이름은 넣지 않아요.
   - 목록에서 1·2·3위 번호, "최저 +N원", 최저가 강조 점·핀을 없앴어요.
3. **할인 강조 끄기.**
   - '중간보다 N% 싸요', '할인율 큰 순', '할인 큰 시술 모음'을 뺐어요.
   - 정가·할인율은 가격 근거(가격마다 있는 i 버튼) 안에서만 보여줘요.
4. **가격은 정보와 함께.**
   - 시술 화면의 가격 요약 바로 아래에 "가격과 함께 꼭 확인하세요" 카드가 와요.
     - 시술 조건, 장비·약제 정품 표기, 시술 의료진, 주요 부작용, 주의사항
   - 가격 근거 시트에도 같은 항목이 있어요.
   - 홈·전체 가격표·장바구니에는 "가격만으로 고르지 마세요" 안내를 붙였어요.
5. **없는 정보는 지어내지 않기.**
   - 정품 여부와 의료진 전공은 앱이 확인하거나 모으지 않아요. 그 사실을 그대로 적어요.
   - 병원이 상품명에 '정품'이라고 적은 경우에만 "병원 표기(앱이 확인한 것 아님)"로 보여줘요.
6. **광고·제휴로 순서가 바뀌지 않아요.** 지금 광고·제휴·수수료는 없어요(`ads: false`, `booking: false`).

## 2. 지시서 해결책과의 대응
| 지시서 해결책 | 한 일 | 안 한 일과 이유 |
|---|---|---|
| '최저가순' 단독 정렬 대신 다양한 필터 | 지역·이름순(기본), 가까운순, 최근 확인순, 낮은 가격순, 높은 가격순. 전체 가격표는 단위당 가격·상품명순도 | — |
| '거리순' | 가까운순. 위치를 정하면 기본이 돼요 | — |
| '리뷰많은순' | **만들지 않았어요** | 리뷰 데이터가 없어요. 없는 리뷰 수로 정렬하면 지어낸 정보가 돼요. 리뷰를 모으는 것 자체도 의료광고(치료 경험담)로 볼 수 있어 별도 법률 검토가 필요해요 |
| '추천순' | **만들지 않았어요** | 추천 기준을 만들면 그 자체가 특정 병원 추천이 돼요. 앞선 지시(AI 추천 1위 금지, 광고비에 따른 순위 조정 금지)와도 충돌해요. 대신 '최근 확인순'을 뒀어요(정보의 최신성) |
| 부작용·주의사항 함께 명시 | 시술 화면 가격 바로 아래 카드, 가격 근거 시트 | 지식 베이스가 의료진 검수 전 초안이라 '초안' 표시를 함께 보여줘요 |
| 장비 정품 여부 | 병원이 상품명에 적은 '정품' 표기만 그대로 보여줘요 | 앱이 정품을 확인할 방법이 없어요. 확인하지 않았다고 적어요 |
| 샷 수 | 시술 이름·용량이 같은 가격끼리만 비교. 요약 카드의 '시술 조건'에 명시 | — |
| 의료진 전공 | "앱은 의료진 정보를 모으지 않아요. 병원에 확인하세요" | 공개된 정보를 모으지 않았어요. 모으려면 수집 범위·표시 방식부터 검토가 필요해요 |

## 3. 화면별 변경
| 화면 | 전 | 후 (기본 설정) |
|---|---|---|
| 시술별 비교 · 요약 | "현재 최저가 60,500원 · 블리비 구리점" | "같은 조건 가격 범위 60,500원 ~ 350,900원", 중간값, 가격 차이, 비교 지점 수. 병원 이름 없음 |
| 시술별 비교 · 바로 아래 | (없음) | "가격과 함께 꼭 확인하세요": 시술 조건 · 정품 표기 · 시술 의료진 · 주요 부작용 · 주의사항(검수 상태 표시) |
| 시술별 비교 · 조건부 가격 | "조건부 최저 51,700원 · 블리비 구로점" | "조건부 가격 51,700원~" + 조건. 병원 이름은 '조건 확인'을 눌러야 보여요 |
| 시술별 비교 · 지점 목록 | 가격순 기본, 1~3위 표시, "최저 +N원" | 지역·이름순 기본, 정렬 5가지, 번호·최저 대비 없음, 정렬 기준 안내 |
| 시술별 비교 · 분포 그래프 | 최저가 점 진하게 + 범례 '현재 최저가' | 모든 점 같은 모양(조건 없는/조건부 구분만) |
| 시술별 비교 · 브랜드 | 브랜드별 최저 지점·가격, 싼 순 | 브랜드별 가격 범위·지점 수, 브랜드 순서 고정 |
| 시술별 비교 · 정가 대비 할인율 카드 | 있음 | 숨김 |
| 시술별 비교 · 복사 | "최저가 3곳"(병원 이름) | "가격 요약"(범위·중간값·지점 수 + 확인 안내) |
| 전체 가격표·검색 | 기본 '싼 순', 할인율 순, "N%↓", "N곳 중 M위" | 기본 '지역·이름순', 높은 가격순 추가, 할인 정렬·배지·순위 숨김, 행마다 '가격 근거' |
| 홈 · 인기 시술 | 최저가 + 병원 이름 + "중간보다 71% 싸요" | 중간값 + 범위 + 지점 수. 병원 이름·할인 문구 없음 |
| 홈 · 죠미의 오늘의 발견 | 중간값보다 많이 싼 곳(병원 이름) | 병원마다 가격 차이가 큰 시술(범위·중간값, 병원 이름 없음) |
| 탐색 · 지점 순위 / TOP 5 | 있음 | 숨김(`#rank`는 꺼짐 안내) |
| 지점 화면 | 가격 수준 순위, "이 지점이 제일 싼 시술" | 숨김. 가격 행은 '가격 근거' 버튼 |
| 지도 | 최저가 핀 진하게, 목록 싼 순 | 강조 없음, 목록은 거리순(위치 있을 때) 또는 지역·이름순 |
| 장바구니 · 요약 | "예상 총액 399,300원 · 최저가 지점 …" | "예상 총액 399,300원 ~ 1,186,900원 · 49곳". 지점 이름 없음 |
| 장바구니 · 상품 행 | "가장 싼 곳 · ○○점" | 지점별 가격 범위 · 가능 지점 수 |
| 장바구니 · 병원별 비교 | 합계 싼 순, "가장 싼 곳" 카드, "1위보다 +" | 지역·이름순 기본 + 가까운순·합계 낮은순·높은순. '가장 싼 곳' 카드와 순위 문구 없음 |
| 장바구니 · 나눠 받기·브랜드·지역 | 최저 지점 이름, "N원 아낌" | 합계 범위, 참고값 안내 |
| 떠 있는 장바구니·공유 문구 | "한 곳 N원부터", "한 곳 최저: ○○점" | "병원별 견적 N곳", "예상 범위(N곳)" |

- 알림의 "새 최저가" 종류는 사용자가 고른 알림이라 그대로 뒀어요.
- 지점 비교(A vs B)도 사용자가 고른 두 곳을 맞대는 화면이라 그대로 뒀어요.

## 4. 기능 플래그 (`app/config.js`)
| 플래그 | 기본 | 켜면 |
|---|---|---|
| `lowestHighlight` | `false` | 이전처럼 최저가 지점 헤드라인, 1~3위, 최저가 핀, 브랜드별 최저 지점, 장바구니 '가장 싼 곳' |
| `branchRanking` | `false` | 지점 순위, TOP 5, 지점 화면의 순위·'제일 싼 시술' |
| `discountEmphasis` | `false` | '중간보다 N% 싸요', 할인율·중간 대비 정렬, 할인 큰 시술 모음, 정가 대비 할인율 카드 |

- 세 플래그를 켜면 이전 화면이 돌아오는지도 테스트로 확인해요(`objective.js` 마지막 부분).
- 법률 검토에서 허용 범위가 나오면 플래그만 바꾸면 돼요.

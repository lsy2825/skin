기준일: 2026-10-14. 화면: 마이 → '데이터 상태·앱 설치'(`#data`, 예전 '알아두면 좋은 점' 화면 맨 위). 코드: `app/app.js`의 `dataStatusCard`·`recheckQueue`·`installCard`·`deviceCard`, 머리말 `#upd`, 안내 줄 `#netbar`. 테스트: `tests/e2e/pricenow.js`('데이터 상태' 2개), `tests/e2e/data_sync.js`.

## 2. 어디서나 보이는 상태
- **머리말 점**(`#upd` 앞): 초록 = 최신, 노랑 깜빡임 = 받는 중, 진한 노랑 = 오래됨·일부 실패, 빨강 = 오류. 동작 줄이기 설정이면 깜빡이지 않아요.
- **안내 줄**(`#netbar`, 머리말 아래)
  - 오프라인: "저장된 가격 정보입니다. 현재 가격과 다를 수 있습니다. (YYYY-MM-DD 수집)"
  - 새 가격 준비: "새 가격(날짜)이 준비됐어요 · 새 가격 보기"
  - 받는 중: "저장된 가격 표시 중 · 새 가격 받는 중 N%"
  - 받기 실패: "새 가격을 받지 못해 저장된 가격을 보여줘요 · 다시 시도"
  - 오래됨: "가격이 N일 전 것이에요. 예약 전 병원에 꼭 확인하세요."

## 3. 공개 범위 (내부 정보와 구분)
| 사용자 화면(데이터 상태) | 운영 현황(마이 → 운영 현황, `flags.ops`) |
|---|---|
| 지점 수·확인 수·실패 수, 바뀐 가격, 원칙, 신고 방법 | 수집 보고 원문, 브랜드별 STALE·EXPIRED·PENDING_REVIEW 수, 급변 검토 큐(승인 방법), robots·약관 검토 상태, 재수집 순서 상위 10곳과 점수, 기능 플래그 |
| 서버 내부 주소·키·로그는 보이지 않음 | 저장소 Actions 링크 |

- 운영 현황도 공개 저장소의 정보만 보여줘요.
- 서버 비밀값은 앱 어디에도 없어요(`tests/security/scan_secrets.py`).

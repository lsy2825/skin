## 3. 남긴 것 (NEEDS_REVIEW)
- **X35 "(여) 겨드랑이 제모 1회"**: 직접 만든 브랜드 간 비교 묶음이에요. 일부러 장비를 가리지 않고 묶었어요(아포지 플러스·클라리티·포토나·젠틀맥스·엘리트). 소비자가 "겨드랑이 제모 1회"를 병원끼리 견주는 흔한 방식이라 남겨요. 다만 장비가 다르다는 사실을 화면에 알려야 해서, Release B에서 '제품·장비가 섞여 있어요' 안내와 장비별 거르기를 붙였어요(`TREATMENT_TAXONOMY.md`).
- **F-10 같은 판매가 두 줄**: 병원 원본이 실제로 두 번 올린 거예요. 조건이 달라 사람이 판단해야 해요.
- **고우리 1회 + 더마샤인 패키지** 같은 이름 2개: 패키지 이름 규칙(묶음 제목 처리)을 바꾸면 다른 패키지가 잘못 합쳐질 수 있어 그대로 둬요.

## 4. 화면 점검 (버튼·오류·가짜 성공)
`tests/e2e/audit_ui.js`가 화면 18개(홈·탐색·관심·변동·가격표·데이터 상태·사전·고민·비교·지도·순위·용어·빠른 비교·검색·장바구니·마이·운영·A/B)의 버튼·링크를 실제로 눌렀어요.
- 버튼마다 주소 변화, 화면 변화, 새 창, 내려받기 중 하나가 있으면 "반응 있음"이에요.
- 일부러 밖으로 나가거나 이 기기 자료를 지우는 버튼은 각자의 테스트에서 확인하고 여기선 건너뛰어요. 설치, 원본 페이지, 전화·길찾기, 공유, 잠그기, 초기화, 저장된 가격 지우기가 그래요.

## 5. 버튼 점검 결과
| 실행 | 결과 |
|---|---|
| 1차 | "반응 없음" 184개 → **테스트 결함**이었어요. '설정 초기화' 같은 버튼이 페이지를 새로 열면 화면 변화 감지기가 사라져, 그 뒤 버튼이 모두 반응 없음으로 잡혔어요. 테마 '밝게/어둡게'처럼 동작이 분명한 버튼까지 포함됐어요 |
| 2차(감지기를 다시 붙이고, 초기화·잠그기 건너뜀) | 버튼 164개를 실제로 누름 → **반응 없는 버튼 0개, 스크립트 오류 0개** |

- 가려지거나 화면 밖이라 누르지 못한 버튼은 판정하지 않았어요. 1차 397개 중 2차에서 누른 건 164개예요. 그래서 "모든 버튼이 동작한다"가 아니라 "누른 164개는 동작했다"예요.
- 가짜 성공 화면(서버 없이 '완료'만 띄우는 것)은 기능별 테스트가 확인해요.

  - 알림 저장: 저장된 뒤에만 토스트(`jomi`)
  - 설치 버튼: 브라우저 허락 신호가 있을 때만(`pricenow` S22)

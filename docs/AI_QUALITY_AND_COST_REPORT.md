# AI 품질·비용 보고서 (5.1)

기준일 2026-10-14. **결론부터: AI(사진 읽기·죠미 AI 답)는 실제 API로 한 번도 호출하지 않았어요.** OpenAI 키와 라이선스가 확인된 병원 홍보 이미지가 이 환경에 없기 때문이에요. 그래서 이 보고서의 측정값은 ① AI 없이 도는 결정론 글 읽기·매칭 파이프라인(사진 읽기 결과도 결국 이 매칭을 거쳐요)과 ② 모의 API로 확인한 비용 통제 장치뿐이에요. 사진 인식 정확도·토큰·실제 비용은 **측정하지 않았고, 지어내지 않아요.**

## 1. 평가 자료

- `tools/eval_offers.js`: `app/data.json`(2026-10-14)에 실제로 모은 병원 옵션 이름·가격을 이벤트 글 한 줄로 바꾼 것(공개 웹페이지에서 모은 우리 데이터, 이미지 아님). 정답 = 그 줄이 데이터에서 속한 비교 묶음과 가격.
- 무작위 표본 5개 × 400줄(seed 7·11·23·31·47), 묶음이 하나뿐이고 '+' 패키지가 아닌 줄만.
- 한계: 실제 포스터보다 쉬워요(한 줄 한 가격, 장식·배치 없음). 사진 OCR 오류는 포함되지 않아요.

## 2. 결과 (결정론 파이프라인)

| 지표 | 5.0 매처(seed 7) | 5.1 매처(5개 표본) |
|---|---|---|
| 가격 읽기 정확도 | 100% | 100% |
| 줄 읽기 성공 | 100% | 100% |
| '정확히 같은 묶음'(EXACT) 비율 | 51% | 37.8~43% |
| **EXACT 정밀도**(같다고 한 것 중 진짜 같은 묶음) | **86.8%** (오답 27) | **94.7~98.8%** (오답 2~8) |
| 비슷한 묶음(PARTIAL)일 때 최선 후보가 정답 | 61.8% | 73% 안팎 |
| 처리 시간 | 0.65ms/줄 | 0.9ms/줄 |

- 5.0의 오답 중 위험한 것: '외국산'을 '국산' 묶음으로(문자열 포함 문제), '1cc'를 '1cc + 1cc'로, '독일산 1부위'를 '1+1'로, '프리미엄(고순도·내성)'을 일반으로. 모두 고쳤어요(`CRITICAL_ISSUES_AND_FIXES.md` I-02).
- 5.1 남은 오답의 대부분은 데이터 쪽에서 사실상 같은 묶음이 둘로 나뉜 경우(예: '국산 바디 보톡스 100U' vs '… 승모근 종아리 100U'), 일부는 성별이 없는 묶음과 있는 묶음(허벅지 제모). 다른 시술·다른 용량을 같다고 한 경우는 표본에서 '점 빼기(크기 미표기)' 류가 남았던 것을 크기 규칙으로 막았어요.
- 정밀도를 올린 대가로 EXACT 비율이 51% → 약 40%로 줄었어요. 나머지는 '비슷한 묶음·후보 여러 개'로 보여주고 판정('높아요/낮아요')을 하지 않아요 — 틀린 판정보다 판정 보류가 낫다는 원칙.
- 모호한 경우 처리: AMBIGUOUS 70~95건/400줄. 이유를 화면에 보여주고 사용자가 고칠 수 있어요(무료).

## 3. 비용 통제 (구현·모의 테스트)

| 장치 | 값 | 테스트 |
|---|---|---|
| 작업당 상한 | `AI_MAX_KRW_PER_JOB` 60원 | 코드 |
| 사용자당 하루 호출 수(실패 포함, KST) | `AI_MAX_USER_CALLS_PER_DAY` 30 | api 13: 한도 2로 두고 두 번째 작업 429 |
| 서비스 하루 AI 비용 | `AI_MAX_SERVICE_KRW_PER_DAY` 30,000원 | 함수 단위(commerce_ai_guard) |
| 비용표 없는 모델 | 호출 거절(503) | api 13 |
| 대체(강한) 모델 | 첫 호출이 아무것도 못 읽었거나 일시 오류일 때 1번만, `FALLBACK`으로 기록, 사용자 추가 차감 없음 | api 7 |
| 비용 기록 | 호출마다 토큰·비용(호출일 가격표), 가격표 없으면 '가격표 없음'으로 세기 | api 7 |
| 출력 상한·시간 제한 | 1,500토큰·45초 | 코드 |

## 4. 아직 측정하지 못한 것 (실제 키가 생기면 바로 할 일)

`server/src/ai/openai.mjs`를 그대로 쓰는 평가: 라이선스가 확인된 이미지(병원 동의 또는 직접 촬영한 공개 게시물) 50~100장 + 사람이 만든 정답(상품·가격·규격·조건) → 상품 추출 정확도, 가격 정확도, 규격 정확도, 조건 정확도, 실패율, 평균 입력·출력 토큰, 성공 1건당 비용, 재시도·대체 모델 비율. 결과는 `ai_usage_records`의 실제 사용량으로 계산해요. 모델 단가는 공급자 가격 페이지에서 확인한 값만 `model_cost_config`에 넣어요.

## 3. 복구 절차

1. 보고서(`data2/report.md`, 실행 요약)에서 '지난 자료 유지' 브랜드 확인 → 사이트 구조 변경 여부 확인 → 수집기 수정 → `workflow_dispatch`로 재실행.
2. 잘못된 자료가 이미 배포된 경우: `data2/accepted/<brand>.csv`를 이전 커밋 것으로 되돌리고 `--skip-scrape` 재빌드(원본 가격 삭제 없음).
3. 급변 검토: `data2/review.csv` 확인 → 맞으면 `data2/review_ok.csv`에 추가.

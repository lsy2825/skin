# 광고 없는 기간 (Ad-free entitlement)

## 1. 지금 상태

- **앱에는 광고가 없어요**(`FLAGS.ads = false`, 광고 코드 자체가 없음). 광고 없는 기간은 나중에 광고를 붙이더라도 이 기간에는 보이지 않게 하는 *권리*만 관리해요. 광고를 넣는다는 결정이 아니에요.
- 광고를 붙이게 되면: 가격 정보·병원 배치와 완전히 분리, '광고·협찬' 표시, 가격 순위에 영향 없음(지시서 · `OBJECTIVE_DISPLAY_POLICY.md`). 의료광고 규정 검토가 먼저예요(NEEDS_LEGAL_REVIEW).

## 2. 규칙 (구현·테스트됨)

| 규칙 | 구현 | 테스트 |
|---|---|---|
| 묶음마다 일수(MINI 7 · STANDARD 21 · PLUS 45) | 주문 스냅샷 `adfree_days` | 원장 1 |
| 연장은 max(지금, 현재 끝) + 일수 | `commerce_fulfill_payment` | 원장 9, e2e C6 |
| 크레딧과 별개: 기간이 끝나도 크레딧은 그대로 | 별도 표 `ad_free_entitlements` | 원장 9 |
| 지급 기록 | `ad_free_grants`(주문당 한 줄, from/to) | 원장 9 |
| 전액 환불이면 그 묶음 일수 제거, 두 번 빼지 않음 | `revoked_days` | 원장 8, api 4 |
| 부분 환불은 기간 유지 | – | 원장 8 |

## 3. 화면

- 크레딧 화면: '광고 없는 기간: YYYY-MM-DD까지 / 없음', 안내 문구 "기간이 끝나도 크레딧은 그대로 남아요. 지금 앱에는 광고가 없어요."
- 충전 확인 시트: "광고 없는 기간 N일 (지금 기간 끝에 이어 붙여요)".
- 서버 모드에서는 `GET /v1/wallet`의 `ad_free_until`(지난 날짜면 null)만 믿어요.

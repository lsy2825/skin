## 3. 이번에 찾아 고친 결함
| 결함 | 어떻게 찾았나 | 고친 것 |
|---|---|---|
| 검색 `300샷`이 `1300샷`에도 걸림(글자 포함 검사) | 지시서 2.1 점검 | 숫자+단위를 상품명에서 통째로 읽어 비교(`Search.qtys`) |
| 검색 `-파워`가 거꾸로 '파워'를 포함해서 찾음(정규화가 '-'를 지움) | 〃 | 연산자 해석을 정규화 전에 |
| 알림이 화면의 부가세 표시·지역 필터 값을 써서, 설정만 바꿔도 '새 최저가'가 울릴 수 있음 | 알림 엔진 설계 중 | 병원 표시가 + 알림의 지역으로 계산, 예전 알림은 한 번 조용히 기준 재설정 |
| 재방문에도 HTML 미리 받기가 `data.json`을 다시 요청 | `data_sync` 실패(요청 1번) | 미리 받기를 `gate.js`로 옮겨 저장본이 없을 때만 |
| 장바구니 요약의 긴 배지가 320px에서 26px 넘침 | `pricenow` S23 실패 | 줄바꿈 허용 |

## 4. 돌리지 못한 것
- 실제 iPhone·Android에서의 설치·휴대폰 알림·오프라인(실기기 없음)
- 배포 주소에서의 동작(접속 막힘) — Actions 배포 성공만 확인
- 참고 사이트의 버튼 동작 비교(수집 도구는 읽기만 가능)
- 느린 회선 첫 방문 속도의 새 측정(미리 받기를 `gate.js`로 옮긴 뒤) — 같은 시점에 요청이 시작되도록 했지만 숫자로 다시 재지는 않았어요

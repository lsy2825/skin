# 고급 장바구니 계획 명세 (ADVANCED_CART_PLANNER, 2크레딧 · 30일)

## 1. 계산

무료 장바구니와 **같은 엔진**(`Pricing.lineCost`, `limitOnce`, `compareClinics`)을 `pricectx.cart()`로 불러요. 유료 부분은 엔진이 아니라 저장·재계산·예산 비교를 한 장에 담은 보고서예요.

| 계획 | 뜻 |
|---|---|
| A. 한 곳에서 모두 | 모든 시술 가격이 있는 지점들의 합계 범위(최저~최고)와 가능한 지점 수 |
| B. 시술별로 나눠서 | 시술마다 가장 낮은 지점(동점이면 이미 고른 지점), 방문 곳 수 |
| C. 최대 2곳 | 두 지점으로 나눌 때 가장 낮은 합계(한 곳보다 싸지 않으면 없음) |

- 가격이 없는 시술을 0원으로 넣지 않아요(그 계획은 '계산 불가').
- 첫 방문가는 지점당 1개만(나머지는 다음 가격으로).
- 2회째부터는 일반가(특가는 한 번).
- 부가세: 병원 표시가 기준(별도 표기 지점은 결제 때 10% 더) — 안내 문구로 표시.
- 예산을 넣으면 계획마다 '예산 안/넘음'.
- 지역: 시·도 하나를 고른 경우 그 지역만, '수도권'·전국은 전국으로 계산(화면에 표시).
- 병원 이름을 앞세우지 않아요(② 지시: `lowestHighlight` 끔). 보고서의 숫자는 합계·방문 수만.

## 2. 30일 이용권

- 차감에 성공하면 `premium_entitlements`(기능, 범위 = 정렬한 `시술x횟수` 목록 + 지역, 30일).
- 같은 범위로 다시 계산하면 0크레딧 작업(새 보고서, 최신 데이터). 다른 장바구니·다른 지역은 새 범위라 2크레딧(테스트: 원장 4, api 6, e2e C20, commerce 2).

# 죠미 동작 명세 (Interaction Spec)

기준일: 2026-10-13. 실제로 동작하는 것만 적었어요. 확인 결과는 `JOMI_UI_UX_QA.md`에 있어요.

## 1. 컴포넌트 (app/app.js)
| 이름 | 하는 일 |
|---|---|
| `JOMI` (`app/jomi.js`) | 레지스트리: 파일 경로, 표정 11종과 상태, 대사 |
| `jomiImg(expr, kind, size, alt)` | 표정 ID의 그림. 그 표정 그림이 없으면 원본 포즈를 써요. `data-expr`에 표정 ID가 남아요 |
| `jomiSay(expr, text)` | 죠미 얼굴 + 버터색 말풍선 한 줄(시술 사전) |
| `jomiEmpty(expr, title, …)` | 빈 화면: 그림 + 제목(죠미의 말) + 안내 + 다음 행동 |
| `jomiToast(expr, text, [label, fn])` | 얼굴 + 한 줄 + 버튼 하나(되돌리기·관심 보기·알림 관리) |
| `jomiSheet(full)` | 소개 시트 |

## 2. 소개 (Introduction)
- **여는 곳:** 상단 바의 죠미 얼굴(`#jomibtn`), 홈의 인사 버튼(`.jomi-hello`)
  - 처음 들어왔을 때 저절로 뜨지 않아요. 누를 때만 열려요.
- **처음 열 때(전체 소개)**
  - 큰 그림, 이름 "죠미 / Jomi", 역할 태그
  - 자기소개 4줄(지시서 문구 그대로)
  - 하는 일 3가지, "진단·추천은 하지 않아" 안내
  - 버튼: '피부 고민 탐색'(기능 플래그가 켜져 있을 때), '시술 가격비교'
  - 닫기 버튼
- **그다음부터(짧은 인사):** "또 왔네! 오늘은 어떤 시술이 궁금해?" + 같은 버튼 2개 + '전체 소개 다시 보기'
- **기억:** `localStorage` `pc:jomiSeen` = 처음 본 날짜만 저장해요. 홈 인사도 처음/재방문 문구가 달라져요.
- **닫기**
  - Esc, 바깥(어두운 부분) 누르기, 닫기 버튼
  - 페이지가 바뀔 때(뒤로 가기·링크)도 닫혀요. 이번에 모든 시트에 적용했어요.
- **포커스**
  - 열면 시트 안으로 가고, Tab은 시트 안에서만 돌아요.
  - 닫으면 연 버튼으로 돌아가요.
- **뒤 화면 스크롤 잠금:** 시트가 열린 동안 `html.sheet-open`이에요. 모든 시트에 적용돼요.
- **데스크톱(900px 이상):** 같은 시트가 화면 가운데 대화상자로 떠요.
- **숨은 재미:** 소개 시트의 죠미를 누르면 살짝 뛰고 한마디 해요.
  - 앱 사용 팁만 말해요(의학 내용 없음).

## 3. 시작·로딩·오류
- **스플래시를 따로 만들지 않았어요.**
  - 이 앱은 비밀번호 화면이 먼저 떠요. 거기에 죠미 얼굴 + '윤실장' 로고타입 + 등장 애니메이션을 넣어 브랜드 화면 역할을 해요.
  - 비밀번호를 이미 푼 탭에서는 바로 앱이 떠요.
- **로딩:** 가격 파일(약 6 MB)을 읽는 동안에만 보여요. 인위적으로 기다리게 하지 않아요.
  - 죠미 얼굴 + "오늘의 가격을 살펴보는 중…"(`role="status"`) + 뼈대 화면
  - 빨리 읽히면 거의 보이지 않아요.
- **오래 걸릴 때:** 12초가 지나도 못 읽으면 "평소보다 오래 걸리고 있어…"와 '새로고침' 버튼이 나와요.
- **실패했을 때:** "잠깐 문제가 생겼어. 다시 시도해 볼까?"
  - 사실만 말해요: "가격 데이터를 불러오지 못했어요. 인터넷 연결이 끊겼거나 서버가 잠시 응답하지 않을 수 있어요."
  - '다시 시도'를 누르면 새로고침 없이 그 자리에서 다시 읽어요.

## 4. 상황별 죠미
| 상황 | 표정 ID | 무엇을 보여주나 |
|---|---|---|
| 홈 인사 | default | "안녕! 오늘은 어떤 피부 고민이 있어?" / 재방문 "또 왔네!…" |
| 피부 고민 가이드 | curious | 질문 말풍선. 결과가 있으면 "적어 준 말과 관련된 정보를 찾아봤어. 결정은 꼭 의료진과 상담해서 해 줘." |
| 시술 사전 | explaining | "스킨보톡스랑 주름보톡스는 뭐가 다를까?…" |
| 검색 결과 없음 | empty | "아직 찾지 못했어. 검색 조건을 바꿔볼까?" + 조건 빼기·전국에서 찾기·비슷한 검색어 버튼(기존) |
| 빈 장바구니 | cart | "아직 담은 시술이 없네!" + 다음 행동 '시술 고르러 가기' |
| 관심 없음 | empty | "관심 시술이 없어요" + 하트 안내 |
| 담기 성공 | happy | 토스트 "담았어!…" + 되돌리기. 버튼이 바로 '담김'이 되고 장바구니 숫자가 튀어요 |
| 관심 저장 | happy | 하트가 채워지며 튀고, 토스트 "저장했어!…" + 관심 보기. 빼기는 기존 되돌리기 |
| 가격 알림 저장 | wink | **저장을 확인한 뒤에만** 토스트 "좋아! 조건이 맞으면 알려줄게." + 저장된 조건 요약 + 알림 관리 |
| 로딩·오류 | sleeping / error | 위 3장 |

- **가격 비교 화면·차트·병원 목록·필터·탭 바에는 죠미를 넣지 않아요.**
- 토스트는 한 번에 하나예요. 새 토스트가 이전 것을 바꿔서 같은 알림이 겹치지 않아요.
- 비교 화면의 아래 바나 떠 있는 장바구니가 있으면 토스트를 그 위로 올려 가리지 않아요.

## 5. 저장하는 것 (이 기기)
| 키 | 내용 |
|---|---|
| `pc:jomiSeen` | 소개를 처음 본 날짜 |
| `pc:lastRoute` | 마지막으로 본 장바구니·지도·가격표·사전·순위·지점 비교·가격 변동·지점 화면 주소. 홈 '이어서 보기'에 써요 |
| (기존) `pc:recentQ`, `pc:recent`, `pc:carts`, `pc:favs` | 최근 검색, 최근 본 것, 장바구니, 관심 |

- 피부 고민 입력 원문은 저장하지 않아요(기존 원칙 그대로).
- 로그인 토큰도 저장하지 않아요(로그인 꺼짐).

## 6. 움직임
| 움직임 | 길이 | 비고 |
|---|---|---|
| 버튼 누름 | 0.14s | `transform: scale` |
| 토스트 | 0.24s | opacity + transform |
| 시트 | 0.32s | 아래에서 위로 |
| 죠미 대기 | 6초마다 한 번 살짝 끄덕임 | 로딩 얼굴에만. 나머지 시간은 정지 |
| 죠미 등장·뛰기 | 0.4~0.5s | 소개 시트·PIN 화면 |
| 장바구니 숫자 | 0.45s | 늘어날 때만 |

- 모두 transform·opacity만 써요.
- `prefers-reduced-motion: reduce`이면 전부 꺼져요(테스트로 확인).
- 깜빡이는 효과는 없어요.

**차단 사유:** 실결제 경로를 한 번도 실제 환경에서 시험하지 않았어요. 법률 검토(LEG03)와 약관이 없어요.

**켜기 전 순서(제안):** 법률 검토 → 약관·환불 문구 확정 → 토스 샌드박스 연결·시나리오(성공·실패·부분 취소·웹훅 누락 → 대사 복구) 증거 → Workers·Supabase 스테이징 배포 → 운영자 소규모 실결제(주인 카드) → 제한 공개.

**되돌리기·감시(켜게 될 때):** `config.js commerce.mode`를 `DEMO`로 되돌리면 구매 화면이 닫혀요. 서버는 `premium_features.active=false`로 기능별 판매 중지. 대사 작업(`reconcile`)의 경보 로그(결제 불일치·환불 누락·AI 예산 초과)를 매일 확인. 이미 결제한 사용자의 크레딧은 원장에 남아요.

**필요한 외부 결정:** 결제사 계약 · 법률 검토 결과 · 주인의 실결제 승인 · 서버 요금제.
